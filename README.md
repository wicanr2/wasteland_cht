# Wasteland 荒野遊俠：繁簡中文重製版

以 Go／Ebitengine 重寫 1988 年 DOS 版《Wasteland》，保留核廢土冒險、隊伍管理與回合戰鬥，
加入中文手札、滑鼠操作、兩種高解析美術與現代介面。

[V2.0.0 新版](#v200-新版) · [V1.0.0 舊版](#v100-舊版) · [玩家回報與修正](#玩家回報與修正) · [如何執行](#如何執行) · [文件與驗證](#文件與驗證)

玩家需自備合法原版。下方圖片供展示成果；原始遊戲資料、完整衍生圖包與含素材的完整包留在本機。

## V2.0.0 新版

正式版號為 `v.2.0.0-20261029`。預設使用源泉圓體、18 像素文字、細邊框與常駐工具列，
支援繁體中文與簡體中文。下圖為最終完整測試包的實際遊戲畫面。

![V2.0.0 實機：HD2 B 手繪高解析、18 像素圓體、細邊框與上下工具列](docs/images/v2.0.0/map-hd2-b.png)

### 優化了哪些事情

| 項目 | V1.0.0 舊版 | V2.0.0 新版 |
|---|---|---|
| 中文 | 繁體中文 | 新增簡體中文；一般文字、選單與 162 段手札都可切換 |
| 字型 | 倚天點陣字，需自備字型 | 內建源泉圓體與 Noto 黑體，從工具列切換 |
| 字級 | 大字點陣排版 | 預設 18 像素，可選 16／18／20 像素 |
| 邊框與版面 | 厚灰框、原版式訊息區 | 細邊框、統一留白與深色面板；地圖可視範圍維持相同 |
| 工具列 | 主要依賴功能鍵與設定選單 | 新增頂部常駐工具列，可選字型、字級、美術、配樂、音量與存讀檔；從「設定 F2」切換語言 |
| 人物與手札 | 點陣文字與舊式訊息視窗 | 人物、物品、手札與設定改為展開面板，文字依面板範圍排版 |
| 美術 | 原版、HD2 A、HD2 B | 沿用三種美術，改由工具列直接切換；下方補齊兩種圖包總覽 |
| 配樂 | 復古與振奮版現代配樂 | 沿用十首重編現代配樂及復古版，可直接切換與調音量 |

兩張對照都使用 HD2 B，展示相同地圖視窗下的介面差異。訊息內容與動畫影格不同。

![V1.0.0 舊版與 V2.0.0 新版實機介面對照，左為舊版，右為新版](docs/images/v2.0.0/ui-before-after.png)

### 新增工具列：選擇語言與字型

頂部工具列將常用設定集中在遊戲畫面中，不必離開遊戲：

| 功能 | 操作方式 |
|---|---|
| 語言 | 點「設定 F2」，再點語言按鈕或按 `L`，切換繁體中文／簡體中文 |
| 字型 | 點「字型 圓體／Noto」，切換源泉圓體與 Noto 黑體 |
| 字級 | 點字級旁的 `−`／`+`，選擇 16／18／20 像素 |
| 美術 | 點「原版／A／B」，切換原版、細緻像素與手繪高解析 |
| 配樂與音量 | 點配樂按鈕切換復古／現代版，點音量旁的 `−`／`+` 調整音量 |
| 快速存讀檔 | 點「存檔 F5／讀檔 F9」 |

語言可在標題或一般地圖切換；請先關閉人物、手札等其他操作選單。
切換語言或字型會保留目前隊伍與遊戲進度。實際畫面見下方的繁簡設定截圖，
字型範例可看 [Noto 18 像素](docs/images/v2.0.0/font-noto-18.png)。
玩家回報的修正與確認結果另列於 [回報處理表](#玩家回報與修正)。

### 配樂與驗證範圍

現代版十首配樂已依「振奮人心」的方向重新編排主題動機、銅管、弦樂與節奏，
涵蓋標題、探索、城鎮、設施、戰鬥及結局。復古版保留 MT-32 音色，兩套都能從工具列切換。
1988 年 DOS 原版只有 PC 喇叭音效，這兩套背景配樂都是專案自作。

兩種語言各有 5,285 條一般文字與 162 段手札。語言切換保留遊戲世界、隊伍與存檔內容，
密語答案與熱鍵字母沿用原版。Linux 與 Windows Wine 已抽測美術、字型、字級、繁簡切換、
人物、物品、手札、設施、存讀檔與退出；原生 Windows／macOS 與人工全程通關尚未驗收。
詳細現況以 [CONTEXT.md](CONTEXT.md)為準。

本機交付入口：[V2.0.0 六個測試包](dist-all/v.2.0.0-20261029/README.md)及
[重新錄製的 73 秒推廣影片](dist-all/v.2.0.0-20261029/promo/wasteland-cht-v.2.0.0-20261029-promo.mp4)。
這些含原版素材的產物留在本機，不隨 Git 散布。

## 遊戲內容與修正

玩家帶領 Desert Rangers 探索核戰後的美國西南部。隊伍需要管理彈藥、裝備、傷勢與技能，
透過回合戰鬥、密語與場景互動前進。專有名詞保留中英對照，方便對照當年的說明書與攻略。

| 內容 | 目前接通範圍 |
|---|---|
| 地圖與事件 | 42 張地圖、移動與時鐘、條件閘、密語問答、寶箱與 44 個腳本指令 |
| 隊伍 | 建立角色、屬性與技能、裝備與彈藥、物品轉交、分隊及 NPC 雇用 |
| 戰鬥與設施 | 遭遇、命中與傷害、傷勢、商店、醫生、訓練師與遊俠中心 |
| 中文手札 | 將原本印在紙上的 162 段劇情收進遊戲，保留段落編號與誘餌標記 |
| 結局 | 反應爐操作、自毀倒數與結局已有流程測試；尚未做人工全程通關 |

### 玩家回報與修正

以下修正已收錄於 V1.0.0 與 V2.0.0，新版繼續保留。原回報的門與 NPC 地點尚不明確，
已修正項目、原版行為與仍待定位的問題分別列出：

| 玩家回報 | 處理狀態 | 現在的行為與驗證範圍 |
|---|---|---|
| 角色死亡後無法重新開始 | 已修正 | 全隊死亡後按鍵會重建新局並回到標題；也可按 `F9` 讀取既有快速存檔，清除死亡等舊畫面狀態 |
| 怪物死亡後仍留在地圖，可重複刷 | 已修正 | 戰鬥結算寫回敵人狀態；清除的遭遇不再加入戰鬥佇列。換圖返回、存檔後重新讀取均保留清怪結果 |
| 沒有怪物仍可按 `E` 遭遇 | 確認為原版行為，保留 | 無敵人時仍會詢問是否執行空回合；確認後不會憑空生成怪物 |
| 帶鎖的門可直接穿過 | 抽測通過，原回報仍待定位 | 16 筆實際技能／物品門閘已驗證：條件未滿足會阻擋移動；尚不能據此宣稱所有回報門鎖均已修復 |
| 有些 NPC 無法互動 | 已修正分隊遭遇接線，原回報仍待定位 | 遭遇使用目前操作的分隊，已驗證 JACKIE 的雇用選單與鍵盤互動；其他 NPC 仍需具體地點重現 |

另外補齊地圖狀態存檔，保存怪物、門鎖與寶箱變更，避免只保存隊伍卻遺失地圖進度。
快速存檔採 WLQS v2，可讀取舊 v1 存檔；舊程式無法讀取新版存檔。
修正依據與驗證見 [死亡重開規格](docs/spec/28-party-wipe.md)、
[地圖狀態回歸測試](internal/play/worldstate_test.go)與 [目前狀態表](CONTEXT.md)。

## 如何執行

準備合法原版資料後，使用三平台測試包，或在既有 Docker 工具鏈中執行：

```bash
tools/go.sh run ./cmd/wasteland -mode play
tools/go.sh run ./cmd/wasteland -mode play -locale zh-Hans
tools/go.sh test ./...
```

新版預設繁體中文，字型已內建。開啟「設定 F2」後點語言按鈕或按 `L` 切換繁簡；
請先關閉人物、手札等其他操作選單。舊點陣介面可用 `-ui classic` 啟動，需自備倚天字型，
此驗證路徑僅支援繁體中文。

| 操作 | 按鍵或滑鼠 |
|---|---|
| 移動 | 方向鍵，或點地圖走一步 |
| 遊戲指令 | 點底部按鈕，或按 `U E O D V S R` |
| 人物資料 | 按 `1`–`7` |
| 手札 | `P`；`I`／`K` 換段，`Page Up`／`Page Down` 捲動 |
| 字型、美術、字級與配樂 | 點頂部工具列 |
| 說明與設定 | `F1`／`F2` |
| 快速存讀檔 | `F5`／`F9` |
| 取消與退出 | `ESC` 或右鍵退一層；`F10` 開啟退出確認 |

三平台建置入口：

```bash
tools/package.sh v.2.0.0-20261029 patch linux-x64
tools/package.sh v.2.0.0-20261029 patch windows-x64
tools/package.sh v.2.0.0-20261029 patch macos-universal
```

`patch` 包提供引擎與翻譯，啟動時匯入玩家自己的原版資料；不含原版資料、倚天字型、
配樂與 HD2 圖包。`full-local` 為含本機素材的自留版本。正式交付集中於 `dist-all/<版本>/`，
建置不會自動上傳或發布，既有封包不覆寫。詳見 [封裝說明](docs/packaging.md)。
