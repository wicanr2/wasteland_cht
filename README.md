# Wasteland 荒野遊俠 — 逆向、重製與繁體中文化

把 1988 年 Interplay／EA 的 DOS 版《Wasteland》完整逆向，在 Go / Ebiten 上重寫引擎，
再做繁體中文化。目標是讓後來的華人玩家玩得完、讀得懂這款後末日 CRPG 的開山之作，
並把 1990 年台灣代理商留下的中文說明書一起保存下來。

專案剛起步，目前在最前面的逆向階段。

## 現在做到哪

- 原版 20 個檔案的身分（SHA-256）全部記錄。
- `wl.exe` 確認是 Microsoft EXEPACK 打包，已寫出解包器還原成 169,312 bytes 的可分析映像。
- IDA Pro 9.4 批次工具鏈就緒，解包後的基準資料庫（614 個函式）已建立。
- 資料格式、文字編碼、引擎本體都還沒開始。

細節見 [`CONTEXT.md`](./CONTEXT.md)（專案單一入口）與 [`docs/re/`](docs/re/)。

## 這個專案怎麼工作

逆向先行，而且是硬性的：任何機制都要先在 IDA 裡讀出來、寫成帶位址與雜湊的筆記、
收攏成標記 READY 的規格，才允許寫引擎程式碼。手冊、攻略、社群 wiki 只能在
逆向確實定位不到時暫代，而且必須標明。規範全文見 [`CLAUDE.md`](./CLAUDE.md)。

## 說明書

四份文本會整理成 markdown：軟體世界 1990 年中文說明書（33 張掃描逐頁轉錄，
保留當年的譯名與行文）、官方英文手冊、段落書、社群攻略。
原版的段落書防拷機制不移植，段落內容改以遊戲內手札直接呈現。

## 版權

不散布原版執行檔、資料檔、美術、音樂、說明書掃描與字型。
本專案公開的只有引擎程式碼、工具與翻譯文本，玩家需自備合法原版。
