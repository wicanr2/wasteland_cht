## 契約

1. 新版遊戲預設採此介面，960×720 固定邏輯畫布。原版／HD2 A／HD2 B 只切美術，
   與介面字型、字級分開。保留開發者用的舊介面以重跑原版幾何驗證。
2. 地圖可視範圍維持 864×384，放於 `(24,84)–(888,468)`。地圖、角色及圖片素材
   不因這次排版重新縮放或更動碰撞。邊框與控件依定版工具的尺寸、配色及位置繪製。
3. 工具列單列常駐：原版／A／B、字型、內文字級、雙配樂、音量、F5、F9、F2。
   音樂開關及音效開關仍可從 F2 操作。字級與字型不寫入遊戲存檔。
4. 點擊控制項先由新版介面擁有。該次點擊不得再落到地圖移動、選單或角色上。
   存讀檔、底部指令及文字選項轉為既有輸入，繼續沿同一 Update 路徑。
   退出確認優先於工具列操作，ESC 維持取消，F10 維持確認後存檔退出。
5. 既有文字層提供字元、原始欄列及反白語意。新版以實際字型尺寸重繪，不辨識螢幕像素，
   不把中文譯文當作規則或選項識別。缺少倚天字型仍可使用內建圓體顯示中文。
6. 內文各欄位都以實際字型量寬，明訂文字安全矩形、行距及行數。短欄位超長用省略號；
   訊息可捲動；互動清單、人物、設定、說明與手札可用同風格擴展面板顯示六列，
   保留現有分頁與熱鍵。不得因較小訊息面板而讓原有選項無法讀取或點擊。
7. 戰鬥與設施沿用原始肖像、選單與名單語意，重排在互不重疊的安全矩形。
   七位隊員可完整顯示。選中序號、異常體力、卡彈武器的反白語意保留。
   視窗的空輸入輪詢不重複追加戰鬥選單；已完成指令階段仍照既有路徑結算。
8. 字型採固定來源壓縮嵌入，引擎包可離線顯示中文。保存兩份 SIL OFL 1.1 原文、
   上游版本、下載網址及 SHA-256。這不改變專案本身的 RRSAL-1.0 授權。
   [字型授權入口](../font-licenses.md)與內建字型 `sources.json` 是散布時的來源紀錄。

## 邊界

遊戲規則、亂數、地圖、物品、存檔 schema 與舊交付包維持。新介面不是原版逐像素還原。

本規格不決定版號或公開發布。後續本機封裝依 [封裝說明](../packaging.md)，
開發產物與實際封包的驗證分開保存。
