`internal/play/quicksave.go`、`internal/ui/music.go`

**這裡的每一項原版都沒有**，所以它不引用任何 IDA 位址，
也不得被別的規格當成逆向結論引用。

## 1. 按鍵語意

```
ESC   只取消／退一層 —— 任何一層都不會結束遊戲
F1    說明（再按一次或按任何鍵關掉）
F2    設定（M 音樂開關、+／- 音量、X 音效開關、ESC 關閉）
F5    快速存檔
F9    快速讀檔
F10   離開 —— 先問 Y／N，答 Y 才「先存檔、存成功了再退出」
```

四條不可動搖的規則：

1. **ESC 永遠不結束遊戲。** 玩家把 ESC 當退一層用，任何一層讓它變成離開，
   都會有人在深夜的存檔前一秒失去進度。
2. **F10 是唯一的離開手勢**，而且不直接離開。
3. **一定要問。** 沒有確認就退出，等於把誤觸變成資料損失。
4. **順序不可顛倒：先存檔，存成功了才退出。** 存檔失敗就留在畫面上並取消離開——
   玩家按 Y 是因為相信我們不會吃掉他的進度。

⚠ 面板開著的時候**吃掉所有按鍵**，不轉給地圖。與模式隔離（規格 24 §3）同一個道理：
看著說明按方向鍵應該是關面板，不是一邊看說明一邊走路。

## 2. 快速存檔的檔案

原版的存檔就是 `GAME1`／`GAME2` 本身，而那份是**玩家自備的原版資料**，
`assets.Open` 會驗 SHA-256——寫過就開不起來。所以快速存檔走一份獨立的檔，
一個 byte 都不碰玩家的原版目錄。

```
"WLQS"        magic
u16           版本（目前 1）
u8  ＋ bytes  來源檔名（"game1"／"game2"）
u32 ＋ bytes  存檔明文（0x800）
u32 ＋ bytes  尾段（0xA00 的按鍵巨集）
u32 ＋ bytes  物品表明文（店家庫存）
```

裡面放**解開後的明文**：加密與 checksum（[`re/08`](../re/08-msq-encryption.md)）
是寫回 `GAME1`／`GAME2` 時才需要的，這個檔只有我們自己讀。

預設位置走 XDG：`$XDG_DATA_HOME/wasteland-cht/quicksave.wlq`，
沒設就是 `~/.local/share/` 底下。用 `-quicksave` 換，空字串 ＝ 關掉 F5／F9。

讀檔的三道拒絕：magic 不對、版本不對、**明文長度與目前存檔不一致**。
第三道最重要——長度是存檔佈局的一部分（[`re/30`](../re/30-save-layout.md)），
硬套會把後面的角色記錄整個錯位，而症狀是「角色資料變成亂碼」，
看起來像解碼壞了而不像讀錯檔。

讀完要把所有子模式清乾淨（`resetModes`）：讀檔時可能正停在戰鬥或設施畫面上。

## 3. 背景音樂

原版沒有 BGM，所以這裡的曲子是**重製版自己寫的新作品**，不是抽自原版、
也不冒充原版音色。

- 譜：`tools/make_music.py`（純 stdlib 寫標準 MIDI），四首——
  `theme`（標題與結局）、`desert`（地圖）、`combat`（戰鬥）、`town`（設施與名單）。
- 音源：**Roland MT-32／CM-32L**，1988 年 DOS 遊戲的高階音源，年代與機種對得上。
  `tools/render_music.sh` 在 docker 裡用 munt 算成 wav 再轉 ogg。
- ⚠ 聲部照 MT-32 的規矩不是 GM：**MIDI channel 1 不用**（MT-32 的八個聲部吃
  channel 2–9，節奏在 10），音色編號用 MT-32 內建表。放在 channel 1 會整條軌沒聲音，
  而且是安靜地沒聲音。

**ROM 與 ogg 都不入版控**：MT-32 的控制與 PCM ROM 是 Roland 的韌體，
波形裡也有它的取樣——與倚天字型、原版遊戲資料同一個政策，執行時自備。
`-music` 指到的目錄讀不到就沒有背景音樂，**遊戲照跑**。

音效與音樂共用同一個 `audio.Context`（取樣率 44100）。一個行程只能有一個，
第二次用不同取樣率建會失敗。

## 4. 驗收條件

1. **ESC 不離開**：在地圖、設施、戰鬥、說明、設定、離開確認各送一次 ESC，
   `Update` 都不回 `false`。
2. **F10 要問**：F10 之後 `Mode() == "quit"`；N 取消回原模式，Y 才離開。
3. **先存再退**：Y 之後快速存檔檔案存在且非空。存檔失敗時**不離開**且畫面有錯誤訊息。
4. **快速存讀檔往返**：F5 → 走五步（狀態要真的變）→ F9 → 座標與時鐘回到存的那一刻。
5. **壞檔不弄壞世界**：F9 讀到不是快速存檔的東西，隊伍座標不動，訊息列有話說。
6. **設定夾住邊界**：音量按到底是 0、按到頂是 10。
7. **面板吃按鍵**：說明開著時按方向鍵只關面板，隊伍不移動。
8. **沒有音樂目錄照跑**：`-music` 指到不存在的目錄，遊戲開得起來。
