# 29：滑鼠（重製版自己的路）

狀態：**READY** ｜ 日期：2026-08-16 ｜ 對應 `internal/assets/curs.go`、
`internal/input`、`internal/play/mouse.go`、`internal/ui`

## 1. 原版怎麼做，以及為什麼不照抄

原版的滑鼠**不產生事件**：`sub_18EFE` 先問滑鼠、問不到才 `int 16h`，
問到的時候把游標座標拿去比對 21 筆熱區表（`ds:0CAEBh`），
**命中的區域換成一個按鍵碼**再走鍵盤那條路（`docs/re/43`）。
每個畫面在等輸入前設一個 32 位元的遮罩（`ds:7DF3h`／`7DF5h`）決定哪些熱區有效；
清單類畫面另外靠控制碼 `\x10` 把「每列一個字母」登記到 `ds:8DDCh`。

**重製版不照抄這一套**（使用者定案 2026-08-16：控制走自己的路、功能等價就好）。
理由是它的每一格都綁在原版的畫面座標與遮罩狀態上，而重製版的畫面已經是
960 × 600、訊息視窗的內容也重排過（規格 10、27）；照抄會把一堆
「為什麼是這個數字」的耦合搬進來，換來的功能是一樣的。

**所以這一份不是逆向結論，不得被別的規格當成原版行為引用**（同規格 27 的體例）。
唯一沿用原版的是**游標圖形本身**（`CURS`，`docs/re/57`）——那是美術資產。

## 2. 功能等價的判準

原版滑鼠做得到的事，重製版都要做得到：

| 玩家想做的 | 重製版怎麼收 |
|---|---|
| 往某個方向走一步 | 點地圖視窗：離隊伍最遠的那個軸決定方向 |
| 下指令列的七項 | 點指令列上那一項的字 |
| 選清單裡的第 n 項 | 點訊息視窗那一行 |
| 回答 Y／N | 點訊息視窗裡的 `Y`／`N` 那個字 |
| 取消／退一層 | 按右鍵 |

⚠ **滑鼠不是新的一條輸入路徑**：點擊一律**翻成與鍵盤等價的 `input.Input`**
再送進既有的 `Scene.Update`。多一條平行的處置分支就會有「鍵盤做得到、
滑鼠做不到」的漏洞，而那種漏洞每加一個模式就多一個。

## 3. 區域怎麼分

座標先換算成**原版的字元格**（`col = x / 24`、`row = y / 24`，規格 10）——
分區用格子講，換視窗大小不必重算。

| 區域 | 格子範圍 | 送出什麼 |
|---|---|---|
| 地圖／圖片視窗 | 欄 1–37、列 1–16 | 方向鍵（見下） |
| 訊息視窗 | 欄 1–38、列 18–23 | 那一行的行號（`1`–`6`）或行內的字母 |
| 指令列 | 列 24 | 該項的熱鍵字母 |

**方向的算法**：以隊伍所在的格（視窗的第 (9,4) 格，`docs/re/25`）為原點，
取點擊處的 `dx`、`dy`，**絕對值大的那個軸決定方向**。相等時取水平。
點在隊伍身上不動。這是重製版的決定——原版的地圖視窗根本沒有熱區。

**訊息視窗的行內字母**：那一行如果有 `Y`／`N`／數字，點到哪個字就送哪個。
其餘情況送行號——清單是 `1 鬥毆 2 攀爬…` 這種一行多項的排法（規格 25），
所以**行內字母優先於行號**。

## 4. 游標

`CURS`（2,048 bytes）＝ 8 個圖形，每個 32 × 16 的 EGA 4 平面、平面連續
（`docs/re/57` §1）。一個 32 寬的圖形其實是**兩張 16 × 16 並排**：
左半是遮罩（只有 0 與 15）、右半是圖形。合成照疊圖那一套：
`螢幕 ← (背景 AND 遮罩) OR 圖形`。

⚠ **哪個圖形對應哪個狀態沒有解**（`docs/re/57` §4：找不到讀 `CURS` 的程式碼）。
所以重製版**固定用第 0 個**，不猜。這一條要寫在畫面上看得到的地方
（規格與筆記），不要讓後人以為那是原版行為。

⚠ 游標畫在**高解畫布**上，位置是像素不是格子——它是唯一不對齊字元格的東西。

## 5. 未解與邊界

- 游標圖形與狀態的對應（`docs/re/57` §4）。
- `CURS` 的 32 寬與 overlay slot 21 存背景迴圈的 24 寬對不上（同上），
  重製版不受影響：我們自己合成，不走原版那條存背景／還原。
- 原版的 21 筆熱區表與 `\x10` 每列熱鍵表**不實作**——見 §1。
  它們仍然是已確認的逆向結論（`docs/re/43`），只是重製版沒有用上。

## 6. 驗收條件

1. **點地圖會走**：點隊伍右邊 → 隊伍往右一格；點隊伍身上 → 不動。
2. **點指令列會下指令**：點 `U` 那個字 → 進 `USE` 的第一層。
3. **點訊息視窗會選**：`USE` 的清單開著時點第 n 項那個數字 → 選中它。
4. **右鍵是取消**：任何一層按右鍵等同 ESC，**而且不會結束遊戲**（規格 27 §1）。
5. **滑鼠翻成鍵盤事件**：同一個動作用鍵盤與滑鼠做，結果狀態相同。
6. **游標畫得出來**：`CURS` 解出 8 個 32 × 16 的圖形，左半值域只有 {0, 15}。
7. 沒有滑鼠或沒有 `CURS` 時遊戲照跑（鍵盤全部功能不變）。
