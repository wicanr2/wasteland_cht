## 2. 戰鬥沒有專屬畫面

進戰鬥就是**把地圖視窗換成隊伍名單**（畫面模式 0 → 1），訊息與選單都印在
原本的訊息視窗（6 行 × 38 欄）。離開戰鬥切回 0。

名單一行的欄位順序與欄座標：

| 欄 | 表頭 | 內容 |
|---|---|---|
| 1 | NAME | 名字 |
| `0x11` | AC | 記錄 `+0x1A` |
| `0x15` | AMM | 記錄 `+0x1F` 指到的物品（`& 0x3F`） |
| `0x18` | MAX | MAXCON |
| `0x1C` | CON | CON；**為負或為零時改印狀態字**（`WoundNames`） |
| `0x20` | WEAPON | 裝備的武器 |

**指令階段每問一個人就重畫一次名單**，所以上一個人造成的變化馬上看得到。

## 3. 一回合的畫面序列

```
遭遇開始     「Encounter begins...」＋「… appear at …」
每個成員：
    CON ≤ 0 → 跳過，不出現在提示裡
    印名字 ＋ 指令選單（七個選項）
    選攻擊但沒武器 → 「Your weapon is jammed.」，重問
    選逃跑 → 「Who should run?」→「Which way?」→「… runs.」
結算：
    未命中 → 「… misses.」
    命中   → 「hits … for N」
    打死   → 「… died!」／傷勢字串
    經驗值 → 「… gains N experience.」
```

所有字串都走翻譯目錄（規格 11），**分段控制碼數量必須與原文相同**。

## 4. 中文化的兩條硬規則

1. **熱鍵不跟著翻譯走。** 指令碼是熱鍵字母表的索引；中文選項要把字母顯示出來
   （`R 逃跑`、`A 攻擊`…），不能只留中文。
2. **七個選項一行放不下。** 640 × 400 畫布一行 19 個全形字，選單要重排成多行。

## 5. 驗收

1. 進戰鬥時畫面模式變 1，離開變回 0。
2. 名單每一行的六個欄位都在對的欄座標上；CON ≤ 0 印狀態字而不是數字。
3. 指令階段每問一個人，名單就是最新狀態。
4. 每個選項前面都有它的熱鍵字母，而且字母與指令碼對得上。
5. 一場完整戰鬥的訊息序列跑得完，不會出現空白訊息或 key。
6. 沒有翻譯時整場戰鬥跑英文原文，不顯示 key。
