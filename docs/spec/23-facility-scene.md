# 23：設施場景——踩上去到走出來

狀態：**READY** ｜ 日期：2026-08-15 ｜ 對應 `internal/play`

規格 09 定了設施的規則（價格、治療、學習），規格 18 定了買賣與治療的迴圈。

## 2. 進場的三件事

五支設施處理程式開頭一模一樣（`re/29` §5.4）：

```
1. 把地圖記錄裡那 13 bytes 的地點名稱抄到 ds:7201h
2. 載入這個設施專屬的 ALLPICS 圖（商店 1／醫生 0／訓練師 2／存檔 3）
3. 把名稱印出來
```

⚠ **名稱在記錄裡的起點每個設施不一樣**（商店與醫生 `+0x07`、訓練師 `+0x04`、
存檔 `+0x03`）。用同一個位移讀四種會讀到別的欄位。

⚠ **圖片視窗與地圖視窗是同一塊 288 × 128**（規格 03 §2.2）——
進設施就是把地圖換成那張圖，不是另開視窗。

## 3. 狀態機

```
地圖 ──踩到 nibble 6 且記錄 +0x00 的 bit7 設起來──► 設施
                                                     │
                                            載圖 ＋ 印地點名
                                                     │
                                             ┌───────┴───────┐
                                          選單迴圈        ESC／離開
                                       （規格 18 的
                                        買賣／治療）         │
                                             └───────┬───────┘
                                                     ▼
                                              回地圖（座標不動）
```

**踩到設施格不會移動隊伍**——原版是先走過去再觸發，走完之後座標已經是新的，
設施只是接著跑（規格 07 §6）。離開設施時什麼都不用還原。

## 4. Go 介面

```go

// EnterFacility 從地圖進設施。回 nil 表示這一格不是設施。
func (s *Scene) EnterFacility(record []byte) *FacilityScene

// LeaveFacility 回地圖。
func (s *Scene) LeaveFacility()
```

## 5. 未解與邊界

- **`0x1A2C0`（存檔／管理）與 `0x1B4F0` 還沒定名**（`re/29` §5.4）。
  這一版把它們當成「有名字、有圖、沒有選單」的設施——進得去、看得到、
  按任何鍵離開。**不要替它們發明選單。**
- 訓練師的技能學習迴圈（規格 09 已有規則）這一版**不接選單**，
  只顯示地點名——買賣與治療先接，學習下一輪。
- 圖片編號 0–3 是 `re/29` §5.4 那張表讀出來的；第五種（`FacilityUnknown`）
  沒有圖，**不要猜一個**。

## 5.1 設施在資料裡很少，而且多半要先被改寫出來

42 張地圖合計只有 **7 筆**設施記錄（醫生 2、商店 1、訓練師 3、存檔 1），
而且**現在有格子指到的只有 2 筆**。其餘要靠密語或腳本改寫地圖格才走得到
（`re/29` §5.4.1）。

所以：**「走到設施」不是實作設施場景就會發生的事**——它還相依於
規格 07 的改寫地圖格那條路。驗收要直接餵記錄，不要靠走地圖碰運氣。

## 6. 驗收條件

1. **名稱起點**：四種設施各拿一筆真實記錄解出來，名字都是可讀的 ASCII，
   而且不含 NUL 以外的控制碼。
2. **圖片**：商店 1／醫生 0／訓練師 2／存檔 3，與 `re/29` §5.4 的表一致。
3. **不是設施的記錄**（bit7 沒設）要回 nil，不能當成第 0 種設施。
4. **離開之後**隊伍座標、時鐘、地圖都與進去前相同。
5. 42 張地圖裡所有 bit7 設起來的 nibble 6 記錄都解得開，
   **設施編號不得超出 0–4**。
