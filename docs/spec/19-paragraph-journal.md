## 2. 引用表是編譯期產物

`tools/extract_paragraph_refs.py` 從**英文原文**抽出「字串 key → 段落編號」，
輸出 `docs/re/generated/paragraph-refs.tsv`（只有 key 與數字、不含原文，入版控）。

⚠ **不要在執行期解析翻譯過的文字。** 翻完之後那句話變成「請看第 23 段。」，
格式隨譯者而變；把偵測放在執行期，等於讓譯者的用字決定遊戲讀不讀得到段落。

⚠ `blk:game2:15:61` 的編號是**選單選完才拼上去的**（`docs/re/33` §2），
抽不到，要由呼叫端提供——不要為了讓表看起來完整而猜一個編號填進去。

## 3. 顯示：讀到編號就直接把正文印出來

玩家不必翻紙本、不做編號驗證、不重現任何複製保護。

原版那句 `Read paragraph 23.` 在翻譯層照樣翻成人話（「請看第 23 段。」），
**接著直接開手札那一頁**（`maybeParagraph` → `openJournal`）。

⚠ **不是把正文倒進訊息視窗。** 訊息視窗滿了會自動捲到最後一列
（`docs/re/106`），所以長段落只看得到結尾——162 段裡有 27 段放不下六列，
最長的 38 列。手札那條路有手動捲動（`↑`／`↓`），而地圖上那兩個鍵是走路，
**同一塊視窗沒辦法兩種都要**。

關掉手札會把剛才那句地圖訊息放回去（`openJournal` 存、`ESC` 還原），
所以原版那句話沒有消失，只是被蓋著——它本身也是原版的文字，兩者都留。

## 4. 手札：全開，但分區

`CLAUDE.md` §3.2 要求「保留一份可隨時翻閱的手札介面」。**預設全開**，
忠於紙本——原版的紙本也是全開的，它靠的是前言那段「請你忍住別亂翻」的自律。

分成兩區：

| 區 | 收哪些 | 為什麼 |
|---|---|---|
| **正文** | 遊戲會引用的 82 段 | 這是實際的劇情主體 |
| **附錄** | 其餘 80 段（陷阱、沒被用到的變體、火星誘餌） | **保存**：它們是 1988 年防拷設計的一部分，不能刪 |

附錄要**標明它們是防拷設計**——陷阱段落（1、22、145）遊戲永遠不會叫玩家去讀，
玩家在手札裡讀到會被誤導，而那正是它們當年的設計目的。
重製版不移植防拷，所以要說清楚，不是靜靜混在正文裡。

已讀過的段落**標記出來**（方便玩家回頭找），但不拿來當解鎖條件。

### 4.1 按鍵：換段落與段落內捲動是兩組手勢

| 手勢 | 做什麼 |
|---|---|
| `P` | 開／關手札 |
| `I`／`K`（與 `←`／`→`） | 上一段／下一段 |
| `↑`／`↓`（與 `W`／`S`） | **在同一段落裡捲動** |
| `ESC` | 關閉 |

⚠ **段落不能套訊息視窗那套自動捲動**（`docs/re/106`）。訊息視窗要的是
「最後一行一定看得到」，手札要的是「從頭讀到尾」——套錯的話長段落會直接
跳到結尾，而**畫面上看不出來**：那一段就是從半句話開始，像翻譯本來就是那樣。
162 段裡有 27 段放不下六列，最長的一段 38 列。

⚠ `I`／`K` 只認 `Char`：移動鍵是方向鍵與 `WASD`（`internal/input` 的
`Bindings`），`IKJL` 沒有綁定。標題上寫著什麼鍵，就要真的收那個鍵。

## 5. 段落正文的翻譯

手札這一層只負責「拿編號換正文」，正文從哪裡來由呼叫端決定——
沒有中文就顯示英文原文，跟其餘文字的 fallback 一致。

**中文正文放在自己的目錄檔**：

| 層 | 位置 | 形狀 |
|---|---|---|
| 譯稿 | `translations/zh-Hant/paragraphs/*.md` | 鏡射 `docs/paragraphs/` 的四個檔，段落標題一律 `## 段落 N` |
| 編譯 | `tools/build_paragraphs.py` | 空行 → 兩個 `\x0D`；擋編號重複／超出 1–162、Big5 缺字、只有標題沒正文 |
| 產物 | `translations/paragraphs-zh-Hant.cat` | 與翻譯目錄同一種格式，key 是 `para:<編號>` |
| 載入 | `internal/play.Journal` | `Text(n)` 回 Big5 bytes，查不到回 nil |

譯稿用 markdown 而不是 TSV：段落是好幾百字的散文，塞進單行 TSV 沒辦法審閱。
key 的形狀沿用同一套，所以 Go 那邊**不必多一份讀檔器**。

⚠ 段落書是紙本，不在原版的字串語料裡，所以它不走 `translations/zh-Hant.cat`
那一條線，進度也不算在 4,827 條裡面。

## 6. 驗收

1. 引用表是從英文原文抽的；翻譯改了不影響。
2. 82 個編號都查得到；`blk:game2:15:61` 不在表裡而且不會被猜一個編號。
3. 手札分正文與附錄兩區，兩區加起來是完整的 162 段（一段都不刪）。
4. 陷阱段落 1、22、145 落在附錄，而且帶「防拷設計」的標記。
5. 已讀標記只影響顯示，不擋著不讓翻。
6. 沒有中文正文時顯示英文，不顯示空白或編號。
7. 段落目錄載不到時遊戲照跑，`Text(n)` 一律回 nil。

## 7. 這份規格**沒有**涵蓋

- 162 段的中文譯稿本身（管線已通，翻譯是人的工作；進度見 `CONTEXT.md`）。
- `blk:game2:15:61` 那個選單選項與編號的對應（`docs/re/33` §2）。
- 密語輸入要不要中文化（等輸入比對的程式碼讀出來，`docs/re/33` §4）。
