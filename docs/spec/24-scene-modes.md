# 24：場景模式與按鍵路由

狀態：**READY** ｜ 日期：2026-08-15 ｜ 對應 `internal/play`

規格 21 把戰鬥接到地圖、23 把設施接到地圖。這一份回答剩下那半個問題：
**按鍵送到哪裡、畫面畫哪一種**。

## 2. 三種模式，一個旗標

原版只有**一個** `ds:46B9h`：0 ＝ 地圖、1 ＝ 隊伍名單。設施畫面不另設旗標，
它是「把地圖視窗換成一張圖」。所以重製版也只用一個狀態，三種取值：

| 模式 | 何時 | 視窗裡畫什麼 | 按鍵送給誰 |
|---|---|---|---|
| 地圖 | 預設 | 地圖 ＋ 疊圖 ＋ 隊伍 | 方向鍵 → 走一步 |
| 戰鬥 | `combat != nil` | 隊伍名單（表頭列 14） | 字母 → 指令；ESC → 退回上一個人 |
| 設施 | `facility != nil` | 該設施的 `ALLPICS` 圖 | ESC／Enter → 離開 |

⚠ **兩個場景不會同時成立**。踩到設施格那一步不掃遭遇（規格 21 已經這樣接），
所以不必處理「在商店裡被攻擊」。

## 3. 按鍵路由

```
Update(in)
├─ 離開確認中 → 只收 Y／N，其餘按鍵一律不往下傳
├─ ActionQuit（F10）→ 開離開確認，任何模式都一樣（規格 27）
├─ 說明／設定面板中 → 面板自己收；面板吃掉所有按鍵
├─ F1／F2／F5／F9 → 說明／設定／快速存讀檔，任何模式都叫得出來（規格 27）
├─ 設施中 → ESC／Enter 離開；其餘按鍵吃掉不轉給地圖
├─ 戰鬥中 → in.Char 走 CombatScene.Choose；指令問完就結算一回合
│           ESC 退回上一個人（規格 14）
└─ 地圖   → 方向鍵走一步（規格 04）
```

⚠ **模式中的按鍵不要「順便」轉給地圖**。原版在名單模式下方向鍵不走路
（`sub_17FEE` 在旗標非 0 時擋住地圖繪製，`re/25` §2.5）——
轉下去會變成「在戰鬥裡走路」。

## 4. 畫面

```
Frame()
├─ 設施中 → 肖像框(0,0)–(13,13) ＋ 選單框(14,0)–(39,13) ＋ 名單框(列 14–23)
├─ 戰鬥中 → 同上，肖像換成敵人那一張
└─ 地圖   → DrawMap ＋ 疊圖 ＋ 隊伍 ＋ 外框 ＋ 右邊那一欄（WASTELAND ＋ 計量表）
名單模式：表頭在字元列 15、成員行 16＋n（docs/re/125）
時鐘只有地圖畫面有；訊息視窗三種都有
```

⚠ **名單模式（戰鬥與設施）沒有時鐘。** 時鐘畫在**地圖畫面外框**的上緣
（欄 28、列 0，`docs/re/27` §4）；切到名單模式時那一列是選單框的上緣，
實機截圖上那條線是完整的（`docs/re/127` §3）。照畫的話數字會壓在框線上。

## 5. 未解與邊界

- 逃跑的方向選擇（`Which way?`）與整隊逃跑已在規格 14，這一份只負責把
  按鍵送過去，不重做。
- 設施的選單（買賣、治療、學習）**這一版不接**——規格 23 §5 已經說明；
  這裡只做「進得去、看得到、離得開」。
- 戰鬥中的滑鼠熱區（規格 20）不接。

## 6. 驗收條件

1. **模式隔離**：戰鬥中送方向鍵，隊伍座標不得改變。
2. **設施隔離**：設施中送方向鍵，隊伍座標不得改變；ESC 之後回地圖。
3. **F10 任何模式都叫得出離開確認**；確認畫面上 ESC 是取消不是離開（規格 27）。
4. **畫面**：三種模式各畫一幀都不回錯誤，而且**畫出來不一樣**
   （同一份場景切模式後 `Frame()` 的像素要有差異）。
5. 戰鬥中指令問完會自動結算一回合，並回到指令階段或結束戰鬥。
