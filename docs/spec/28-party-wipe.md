## 2. 三分支

每走一步之後判一次，順序不可換：

```
這一組 0 個人                     → 死亡畫面
每個人都「倒下 ＋ (傷勢等級 ≠ 0 或 狀態位元 ≠ 0)」→ 死亡畫面
還有人站著                        → 什麼都不做
全倒但至少一個人救得回來          → 自動 View（切到下一支有人的隊伍）
```

⚠ **第二條與第四條的差別是「救不救得回來」，不是「倒了幾個」。**
一個 CON ≤ 0 但傷勢等級 0、狀態位元也是 0 的人，是**會自己醒的昏迷**
（`docs/re/35`：不省人事會自己醒，重傷開始才會一路往下掉）。
只要有這種人，這一組就還有救 —— 原版走的是換隊，不是死亡畫面。

原版的迴圈是「找到第一個**不是**『倒下且有傷勢或狀態』的人就跳出去」
（`0x16C3D` 的 `jnb` 與 `0x16C51` 的 `jz` 都跳到 `0x16C64`），
跳出去之後再問一次「還有沒有人站著」決定要不要換隊。
這裡照它的語意寫成上面四條，行為一樣而讀得懂。

## 3. 死亡畫面

原版是**設施畫面那個形狀的第六張**（圖 ＋ 地點名 ＋ 一句話 ＋ 等按鍵），
只是它沒掛在設施跳表上，是 `0x1C570` 手寫的一段。所以重製版也重用設施場景：

| 元素 | 值 | 來源 |
|---|---|---|
| 地點名 | `Grim Reaper` | `ds:DE60h`，13 bytes 明文 |
| 圖 | `ALLPICS` 第 **0x3B**（59）張 | `mov al, 3Bh; call sub_190A6` |
| 訊息 | `Your life has ended in The Wasteland.` | `ds:DE6Dh` 明文 |
| 之後 | 等按鍵 | `sub_18E90` |

⚠ **兩段文字是明文 ASCII，不在打包字串表裡**。抽字串的工具看不到它們，
所以翻譯走 `ui:wipe.*` 與地點招牌那條查表路（規格 27 §2 的同一個做法）。

⚠ **死亡畫面不是遊戲內的重新開始。** 原版沒有讀檔選單（`docs/re/95`），
重來要離開遊戲跑 `SETUP.EXE`。重製版**不做**那條——按鍵之後回標題畫面，
玩家自己決定要不要讀快速存檔（F9，規格 27）。這是重製版的決定，
在畫面上不假裝原版有這個選項。

## 4. 未解與邊界

- **傷勢等級的逐值對照未完成**（`docs/re/99` §3.1）：`sub_19A1D` 的分支結構
  確定，但哪一個 `dl` 對應哪一條傷勢帶還沒與 `docs/re/15` §3 的
  −11／−20／−30／−40 逐值對過。remake 用 `game.Character.WoundLevel`
  （就是那四個門檻）。**這只影響「救得回來 vs 死亡畫面」的邊界**，
  不影響「全倒了要處理」這件事。下一個入口：`ds:CCCDh` 起四個 byte 的值。
- 原版按鍵之後回到哪裡沒有讀出來（`sub_18E90` 之後那一段還沒追）。
  重製版回標題畫面，標明是重製決策。
- `SETUP.EXE` 的「Restart game with old characters」不做——那是 DOS 安裝程式。

## 5. 驗收條件

1. **有人站著就什麼都不做**：一個人 CON > 0，走一步之後仍在地圖模式。
2. **全倒但救得回來 → 換隊**：整組 CON 打到 0 但傷勢等級 0、狀態位元 0，
   而另一組有人 → 走一步之後操作的組換掉了。
3. **全倒且救不回來 → 死亡畫面**：整組 CON 打到 −40 以下 → 進死亡畫面，
   地點名是 `Grim Reaper` 的譯文、圖是第 59 張。
4. **0 人也是死亡畫面**（原版第一個分支）。
5. **死亡畫面按任意鍵回標題**，而且不會再掉回死亡畫面。
6. 死亡畫面那兩句話走翻譯目錄，畫面上是中文。
