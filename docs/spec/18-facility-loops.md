## 2. 庫存

物品表 `+0x02`：

| 值 | 意思 |
|---|---|
| 0 | 缺貨——**不出現在商店列表** |
| `0xFF` | 無限供貨——賣東西給它**不會變動** |
| 其他 | 實際數量，賣一件給店家就 **+1** |

## 3. 賣

```
身上「賣得掉」的東西 0 件 → 訊息「You don't have anything they want!」
選一件：
    把那個槽清成 0（從身上移除）
    加錢（賣價）
    店家庫存 +1（0xFF 不動）
    重新數，只剩 1 件就結束
```

清單會**標記裝備中的物品**（記錄 `+0x1F` 或 `+0x25`），但**不擋著不讓賣**。

⚠ 賣價的公式（`sub_1C1C2`）**還沒逆向**，由呼叫端提供——不要拿買價公式硬套。

## 4. 買

```
物品陣列沒有空槽 → 訊息「Your inventory is full.」
否則開清單（只列庫存非 0 的）
```

## 5. 逐點治療

```
迴圈：
    還差幾點 = MAXCON − CON       ← **每一輪重算**
    差 0 點就沒事做
    按「治療 1 點」：
        錢不夠 → 訊息「You don't have enough money.」，停在這裡
        扣一次「每點價格」（地圖記錄 +0x04）
        CON +1
    按「繼續」或取消 → 結束
```

⚠ **一次按鍵只治一點、只扣一次錢。** 差額算在迴圈外會變成
「錢不夠就一點都不治」，那與原版不同。

## 6. 解毒

```
身上沒有病 → 訊息「You have no diseases.」
否則列出八個狀態位元裡有設起來的那幾個，選一種
每種的價格都是地圖記錄 +0x06（固定，不隨病種變）
錢不夠 → 訊息「You don't have enough money.」
```

## 7. 驗收

1. 庫存 0 的品項不出現在列表；`0xFF` 賣多少次都還是 `0xFF`。
2. 賣掉的槽會被清成 0，錢會增加，店家庫存 +1。
3. 裝備中的物品在列表裡被標記，但賣得掉。
4. 物品陣列滿了就不開買的清單。
5. 逐點治療每輪重算差額；錢不夠時停在中途，已治的點數留著。
6. 治到 CON ＝ MAXCON 就停，不會超過。
7. 沒有病時不開解毒選單。

## 7.1 賣價

**與買價同一個公式，指數換成商店記錄 `+0x04`**（`re/22` §3.1）：

```
價格 ＝ 基礎價 − (基礎價 >> n)      買 n ＝ 記錄 +0x03、賣 n ＝ 記錄 +0x04
```
