   不是把舊 HD 圖包改名，框線不依賴新圖包欄位或原版彩色點陣字型。
2. F2 在語言按鈕左側增加 `C 框線：HD 原版／簡約`，矩形為 `(356,162)–(600,204)`。
   按 C 或點按鈕即時切換，留在設定畫面；按鈕僅在 A／B 顯示。
3. 關閉後回到規格 33 的細框、計量表與版面。開啟保留規格 33 的字型、字級、工具列、
   中文排版及地圖範圍 `(24,84)–(888,468)`，不得修改任何地圖像素、碰撞或規則。
4. 地圖斜框為 `(16,76)–(896,476)`、寬 8；訊息／名單與彈窗沿既有外矩形畫寬 8 框。
   肖像與選單向外擴至 `(16,76)–(320,410)`、`(328,76)–(952,410)`，保留原內容矩形。
   右欄外框 `(904,80)–(948,472)`、寬 4，直排標誌與表管依定版樣稿位置。
5. 計量表讀取現有 `geigerReading` 與 `partyHasGeiger`，表管色彩不更動數值或音效。
   無計數器或無讀值時顯示既有缺值標記。原版畫框逐字模呈現不作為新框線的實作。
6. 框線只影響呈現，不寫入原版存檔、WLQS 或地圖側車檔。語言、字型、美術切換及
   死亡重開／F9 不應遺失此工作階段選項。工具列、設定與退出確認的點擊擁有規則沿用。
