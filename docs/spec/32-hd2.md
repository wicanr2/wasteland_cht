- 切片回歸 13 項通過；完整來源驗證後才建立包。manifest 核對全部圖片的
  SHA-256、尺寸與資產身分，來源收據標為 `complete-local-candidate`。
- `go test ./... -count=1` 與 `go vet ./...` 通過。整合測試以兩個實際本機包
  核對 42 地圖、82 場景、標題／戰鬥／結局，以及切換前後 World、時鐘與隊伍不變。
- Linux Docker 的正常標題畫面按 `S` 開始，經 `F2`、`V` 切換 A／B、切換兩套配樂，
  再經 `F5`、方向鍵、`F9` 與 `F10`、`Y` 正常退出。讀檔後地圖裁切區逐像素還原。
  GUI 操作腳本與收據由製作台帳連結，未用跳過標題或指定地圖取代這條流程。
- 九組地形的開發者定位截圖，以及標題／戰鬥／結局截圖另作抽樣。這些定位截圖
  不稱為正常玩家路徑；場景測試也不等於原版動態對拍。
