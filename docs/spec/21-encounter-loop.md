## 2. 狀態機

```
        走一步 / 節拍滿 0x400
地圖 ──────────────────────────► 遭遇掃描
                                     │
                        掃描說沒有 ───┴─► 回地圖（什麼都沒發生）
                                     │
                                     ▼
                              畫面模式 ← 1（名單）
                              抄一份每個角色的經驗值
                                     │
                                     ▼
                        ┌──► 指令階段（四組依序）
                        │         │
                        │         ▼
                        │      結算一輪
                        │         │
                        └── 還有敵人 ┘
                                     │
                              沒有敵人 / 沒有人下指令
                                     ▼
                        經驗值前後相減 → 逐一報「X gains N experience.」
                              畫面模式 ← 0，回地圖
```

**一輪 ＝ 四組都問完指令，再一起結算**，不是一組打完換下一組。

## 3. Go 介面

```go
// internal/play

// EncounterResult 是一場遭遇跑完的結果。
type EncounterResult struct {
    Fought   bool              // 有沒有真的打起來
    XPGained map[int]uint32    // 角色編號 → 這一場拿到的經驗值
}

// StartEncounter 從地圖進戰鬥。回 nil 表示掃描說沒有可打的，地圖照舊。
func (s *Scene) StartEncounter() *CombatScene

// FinishEncounter 收尾：算經驗值差、切回地圖模式。
func (s *Scene) FinishEncounter(c *CombatScene) EncounterResult
```

⚠ **經驗值差用「前後相減」算，不要另外累加。** 原版沒有「這一場拿了多少」
這個欄位（`re/51` §3）；多開一個累加器就多一個會不同步的狀態。

## 4. 未解與邊界

- **只做一組。** 原版對四個隊伍組各跑一次，但 `DISBAND` 的分隊管理
  重製版還沒做（規格 05 只實作第 0 組）。這一版**只處理第 0 組**，
  四組迴圈的形狀照 `re/51` §4 留在筆記裡，不在程式碼裡假裝有。
- 「這一組不在這張地圖」（字串 54）與「這一組沒被攻擊」（字串 20）
  兩個 Yes／No 提示**不實作**——它們只在多組的情況下出現。
- 結算那一串六支函式各自做什麼還沒對到回合的哪一段（`re/51` §8），
  所以結算沿用規格 12 的回合骨架，不另外加東西。
- `ds:46DFh`（「有旗標就不打」）是誰設的未解；重製版**不設它**，
  等於永遠是 0——與原版預設一致。

## 5. 驗收條件

1. **掃描說沒有可打的就不進戰鬥**：地圖上沒有 nibble 3／15 的格子在視窗內時，
   走一百步都不會切到名單畫面。
2. **畫面模式**：進戰鬥時地圖視窗換成隊伍名單，離開時換回來；
   `Frame()` 兩種模式各畫得出來。
3. **經驗值**：跑一場人為指定結果的戰鬥，`XPGained` 的值等於
   角色記錄 `+0x21`–`+0x23` 的前後差，一個角色一筆。
4. **回得去**：戰鬥結束後隊伍座標、時鐘、地圖都與進戰鬥前相同
   （原版的 `sub_18350` 是重新載入地圖，不是換地圖）。
5. **全滅不當成正常結束**：隊伍全部 CON ≤ 0 時要能分辨，
   不要靜悄悄回到地圖（原版走另一條路，本版先回報狀態）。
