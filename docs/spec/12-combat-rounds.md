## 2. 戰場的形狀

```
三組敵人，每組最多 10 個
每組的資料：+0x00–0x13  10 個 16-bit HP
            +0x14–0x1D  10 個「這回合還沒行動」旗標
```

隊伍最多 7 人（存檔的角色記錄 1–7），與敵人**排在同一張行動順序表**裡。

## 3. 一個回合

```
1. 開始：每個活著的單位把「還沒行動」旗標設起來
2. 排序：逐一算行動值並寫進行動表，寫完就把旗標清掉
      行動值 = 2d6（逢同點續擲）+ 攻擊資料的某欄位 × 8
3. 依行動值輪流行動（誰先動的規則**未解**，見 §5）
4. 打完一輪回到 1，直到一方全滅
```

行動表是**固定格子**（三組 × 10 格 × 2 bytes），索引直接對回單位編號，
不是壓縮清單——所以「第 n 個敵人」在表裡永遠是同一格。

## 4. 單次行動

沿用規格 06：

- 隊伍打敵方：命中 ⟺ `roll(1..100) < 累加值`；傷害是五項相加。
- 敵方打隊伍：命中 ⟺ `roll(1..100) ≥ 累加值`；傷害是基底 ＋ Nd6。
- 兩邊護甲都是 N 顆 d6 的吸收。
- 敵人 HP 減到 ≤0 夾成 0；角色 CON 可為負。
- ⚠ **CON 破 −50 不會在扣血當下歸零**——那是時鐘每 16 刻做的
  （`sub_1251E`，`docs/re/35` §2）。所以戰鬥中 CON 可以是 −60，
  照原版不要在傷害那一層加下限。
- 擊殺之後算經驗值加給攻擊者。

## 5. 未解與邊界

- **行動值算出來之後怎麼排序、誰先動**——只知道值怎麼算、寫在哪，
  排序那一段還沒讀。實作先照「行動值大的先動」，**並在程式碼註明這是暫代**。
- `sub_12ABA` 取的是攻擊資料的哪個位移（行動值的 ×8 那一項）——
  實作收一個參數，不猜。
- **逃跑與隊形**完全沒讀。
- 距離／射程（規格 06 的暫代項）同樣影響傷害。

## 6. 驗收條件

1. 回合開始時，活著的單位旗標全設起來、死的不設。
2. 排完序旗標要全部清掉——**同一個單位一回合不得行動兩次**。
3. 行動表的格子位置：第 g 組第 n 個永遠在 `g*10 + n`。
4. 一方全滅就結束，回合數有上限（避免無限迴圈）。
5. 固定亂數種子跑 1,000 場，不得有 panic、不得有負的 HP、CON 不得溢位翻正；
   **時鐘跑過之後**破 −50 的要被歸零（下限在時鐘那一層，不在傷害那一層）。
