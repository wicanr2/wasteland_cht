# MT-32／CM-32L 的節奏鍵位是量出來的

MT-32 的節奏音色表與 General MIDI 不一樣，而且**不是全鍵盤都有指派**。
送一個沒指派的鍵下去，它就是不出聲，`mt32emu-smf2wav` 不會抱怨，
檔案長度、聲道、音量、格式全部正常。症狀是「鼓聲少了一半」。

上一版的背景音樂就踩了這個坑：腳踏鈸寫 GM 的 42，**從頭到尾沒有響過**。

```bash
python3 tools/mt32_probe.py gen workplace/probe/rhythm.mid
docker run --rm --cpus=2 --network none \
    -v "$PWD/workplace/probe:/p" -v "$HOME/cht/mt32:/roms:ro" \
    wasteland-media:latest \
    bash -c 'cd /p && mt32emu-smf2wav -f -m /roms -i cm32l -o rhythm.wav rhythm.mid'
python3 tools/mt32_probe.py analyze workplace/probe/rhythm.wav
```

## 怎麼量的

鍵 24–87 各敲一下、每鍵間隔 0.5 秒，算成 wav 之後逐段量三個數字：

| 量什麼 | 怎麼算 | 看得出什麼 |
|---|---|---|
| RMS | 敲下去前 0.3 秒的均方根 | 這個鍵**有沒有指派**（貼近 0 ＝ 沒有） |
| 過零率 | 同一段裡波形穿越零點的次數 ÷ 秒 | 高低。大鼓每秒三百多次，鈸上萬次 |
| 尾巴 | 0.3–0.5 秒的能量 ÷ 前 50 ms 的能量 | 收得快不快。**腳踏鈸與碎音鈸都是高頻，差在這裡** |

過零率不是音高，但對打擊樂夠用：分得出低頻鼓、中頻鼓、金屬。
分不出小鼓與手鼓那種同頻段的差別——那要靠耳朵，這份文件不宣稱做得到。

## 量到什麼（CM-32L 音色庫）

掃 64 個鍵，**49 個有聲、10 個沒有指派**：

```
沒有指派：42 44 46 47 48 59 79 80 81 82
```

其中 **42 正是 GM 的腳踏鈸**。照 GM 的慣例寫下去，鼓組會少一整層。

選出來的鍵（照量到的數字挑，不是照慣例）：

| 用途 | 鍵 | RMS | 過零率 | 尾巴 | 為什麼是它 |
|---|---:|---:|---:|---:|---|
| 大鼓 | 30 | 1136 | 313 | 0.27 | 最低也最響 |
| 小鼓 | 27 | 560 | 2160 | 0.08 | 中頻裡最響，而且收得乾淨 |
| 腳踏鈸 | 43 | 149 | 12987 | 0.02 | 最高、收得最快，八分音符鋪滿也不糊 |
| 碎音鈸 | 75 | 270 | 15783 | 1.35 | 最高而且拖最長 |
| 疊音鈸 | 61 | 714 | 5340 | 0.55 | 比腳踏鈸暗、比碎音鈸短 |
| 中鼓（低／中／高） | 53 / 52 / 31 | 597／405／430 | 483／690／743 | — | 三個過零率分得開，過門排得出高低 |

`tools/make_music.py` 開跑前會擋一次：用到那十個無聲鍵就直接中止，
不會讓一首少了鼓的曲子安靜地產出。

## 這件事的一般形式

**音源的鍵位／音色編號不要照別的標準抄。** GM、MT-32、各家 SoundFont
三套編號都不一樣，而抄錯的代價是「安靜地少東西」，不是報錯。
換音源就重量一次——這支腳本三分鐘跑完。
