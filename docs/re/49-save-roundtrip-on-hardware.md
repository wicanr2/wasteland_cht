# 49：存檔改寫的實機驗收

日期：2026-08-15 ｜ 對應 `CLAUDE.md` §4「存檔策略是改寫不是重建」

輸入：`game1`／`game2` 的 SHA-256 見 `docs/re/01`；存檔佈局見 `docs/re/30`。

---

`CLAUDE.md` §4 說存檔要「從原始 bytes 出發只蓋已解欄位，未解區域一個 byte 都不動，
驗收要做到讀出再寫回 byte-for-byte 相同」。前半段單元測試證得了，**後半段證不了**：
「原版還讀不讀得進去」只有原版能回答。

## 1. 兩道關卡

| 關卡 | 怎麼驗 | 結果 |
|---|---|---|
| round-trip | 什麼都不改，讀出來再編碼回去 | `game1`／`game2` 各 4,614 bytes **完全相同** |
| 原版讀得進去 | 改隊伍座標與時鐘，寫回 `GAME1`／`GAME2`，開原版 | **讀得進去**，而且停在指定的座標與時刻 |

4,614 ＝ 6（magic ＋ checksum）＋ `0x800` 加密段 ＋ `0xA00` 未加密尾段。

## 2. 改了什麼

`cmd/wl-save` 只碰三個已解欄位：

| 欄位 | 位置 | 為什麼要一起改 |
|---|---|---|
| 隊伍座標 | 隊伍槽表 `+0x08`／`+0x09`（`docs/re/15`） | 要移動的就是它 |
| 視窗原點 | 全域狀態相對位移 0／1（`ds:464Eh`／`464Fh` 的副本） | **原版不從座標推**，兩邊要一致 |
| 時鐘的「時」 | 全域狀態相對位移 12（`ds:465Ah`） | 要驗晝夜分支 |

checksum 一定重算（`0 − Σ 明文位元組`，`docs/re/30` §2.1）。不重算的話原版
**直接拒收**，而且那是靜悄悄的失敗——檔案看起來好好的。

⚠ **視窗原點是獨立欄位。** 只改座標不改它，載進去畫面會偏——原版把
`ds:464Eh`／`464Fh` 與隊伍座標分開存，不是從其中一個推另一個
（`docs/re/25` §2.1、`docs/spec/05` §3）。

## 3. 實機結果

把隊伍擺到資源 0 的 (57, 39)（輻射帶中央），時鐘設 02:00，開原版：

```
02:04   地圖視窗滿是輻射標誌
        The ground seems to glow here.
```

同一份存檔改成 12:00 再開一次：輻射標誌**全部消失**，地形照常。

兩張都拿 `cmd/wl-shot -mode play -at 57,39 -hour 2`／`-hour 12` 的輸出
逐像素比對地圖視窗那 288 × 128：

| 場景 | 不同的像素 |
|---|---:|
| 02:00（輻射標誌 32 處） | **0** |
| 12:00（沒有標誌） | **0** |

所以這一輪同時驗掉三件事：**存檔寫得回去**、**原版讀得進去**、
**我們畫的那一幀與原版相同**。

## 4. 過程抓到的一個缺口

第一次比對差 **55 個像素**，全部落在隊伍站的那一格（視窗第 (9, 4) 格）：
原版那裡是「地形 ＋ 隊伍」，我們畫成「輻射標誌 ＋ 隊伍」。

原因在 `sub_16716`：它自己取背景，而取的是**第 3 層的地形**——

```
0x1673A  mov  bl, ds:46A6h
0x1673E  mov  di, ds:46CAh    ; 第 3 層
0x16742  mov  ah, [bx+di]     ; 背景 ＝ 地形
0x1674C  mov  al, 7           ; 疊圖 ＝ 隊伍
0x16756  call sub_1000C       ; slot 4 直接**覆寫**螢幕
```

overlay slot 4 不讀螢幕，它從圖形表取背景再寫下去。所以隊伍那一格**永遠是
「地形 ＋ 隊伍」**，先畫在上面的疊圖會被蓋掉——**站在輻射上不會看到輻射標誌**。

重製版的對應規則：掃視窗上疊圖時跳過第 (9, 4) 格
（`internal/game`.`World.ViewIcons`）。

## 5. 可重跑的完整指令

```bash
# 乾淨的可寫副本（tools/dosbox.sh 第一次跑會自己複製）
rm -rf workplace/dosbox/game && tools/dosbox.sh "wait:2" >/dev/null

# 只驗 round-trip
tools/go.sh run ./cmd/wl-save -dir workplace/dosbox/game -check

# 改座標與時鐘並寫回
tools/go.sh run ./cmd/wl-save -dir workplace/dosbox/game -at 57,39 -hour 2

# 開原版看它讀不讀得進去
tools/dosbox.sh "wait:6;key:Return;wait:3;key:p;wait:4;shot:sv01"

# 我們這一側的同一幀

```

## 6. 這一輪學到的（寫成規則）

- **「寫得回去」與「讀得進去」是兩件事。** round-trip 相同只證明我們的編碼器
  與解碼器互為反函數；原版收不收是另一個問題，只有原版能回答。
- **改一個欄位常常要改一組。** 座標與視窗原點是分開存的，只改一半畫面就偏。
  改任何欄位之前先問「還有誰跟它是一組的」。
- **驗收工具自己會擋住第二次驗收。** 資料目錄的 SHA-256 檢查在寫過一次之後
  就不通過了，所以要有一個**明講在跳過驗證**的入口（`assets.OpenModified`），
  而不是把檢查拿掉。
- **一個場景可以同時驗三層。** 選對場景（改寫存檔 → 特殊地形 → 晝夜分支），
  一次對拍就把存檔、載入、繪製三件事一起驗掉。
