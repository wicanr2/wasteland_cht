# 131：角色畫面——地圖數字鍵、裝備／裝填／卸卡彈／交給隊友，與 `+0x25`、`+0x2E`

日期：2026-08-25 ｜ 接 `docs/re/15`（角色記錄）、`docs/re/107`（戰鬥指令結算）、
`docs/re/129`（熱區遮罩表裡那個「選人之後的金錢畫面」）

輸入：`wl.merged.exe`，SHA-256
`cd5b07eaa55f1e1578caa1b05f0bd5331355cd119f387e61b1a8906738e78118`。

玩家在地圖上按 `1`–`7` 開的就是**角色畫面**——`docs/re/129` 那張遮罩表裡
標成「選人之後的金錢畫面」的 `sub_19130`，其實是整個角色管理的主迴圈：
資料頁、物品頁（含裝備／裝填／卸卡彈／交給隊友／丟棄）、技能頁。

---

## 1. 入口：地圖主迴圈的數字鍵（`0x16BFC`）

```
0x16BFC  cmp al, '1'；cmp al, '8'    ; '1'–'7' 才進來
0x16C04  call sub_12760
sub_12760:
  al ← ds:4667h & 0x0F              ; 數字 → 1–7
  > ds:4653h（隊伍人數）→ retn
  call sub_19130                    ; 角色畫面
  call sub_163C4；jmp loc_163A0     ; 回地圖並重建
```

滑鼠那一側（`docs/re/112` 的 `0x18C4C`）：點名片列送 `'0' ＋ 列號`，
走的就是同一條路。

## 2. 主迴圈 `sub_19130`：三頁循環

```
0x19130  CCEDh ← al（隊員）；sub_17029；sub_19362（畫資料頁）
0x19139  熱區遮罩 ← 0x0006_0C04（ESC＋NEXT＋POOL＋DIVIDE，docs/re/129）
0x19145  sub_18E90 等按鍵：
  ESC          → sub_1702E（重畫名片行）收工
  Enter／空白  → sub_19343（物品頁，§3）
  'P'          → sub_19B81（集中金錢，與設施同一支，docs/re/42）
  'D'          → 均分現金（§2.1）
```

資料頁 `sub_19362` 印表 2 字串 137 `NAME: `、138 `SEX: `（＋0x18 → 162／163）、
139 `NATIONALITY: `（＋0x19 → 145–149）——`docs/re/17` §4.3 那三段算術的宿主
就是這一頁；140 `P)ool  D)iv cash` 是它的提示行。

### 2.1 `D` ＝ 把這個人的現金均分給全隊（`0x19165`）

`sub_19A9C` 把這個人的錢載進 `ds:466Bh`–`466Dh` → `loc_18325(bl ＝ 人數)` 除法
（餘數留在 `ds:BA80h`–`BA82h`）→ `sub_198BC(0)` 清掉本人的錢 →
每個隊員各加一份商 → 本人再加餘數。**除不盡的零頭歸自己。**

## 3. 物品頁：`sub_19343` → `sub_19394` → `sub_19202`

`sub_19394` 用 `docs/re/53` 的清單框架列物品（表頭 ＝ 表 2 字串 151
`    ITEM`），選一列進 `sub_19202`；`0xFE` 那條路是**重排物品**（與技能清單
同一套備份還原，`docs/re/92` §3.1），重排時 `+0x1F`／`+0x25` 兩個裝備索引
跟著換算（`0x19422`–`0x19441`）。ESC 依序退回：物品頁 → 技能頁
（`sub_198F0`，表頭 153 `   LVL   SKILL`）→ 收工。

### 3.1 選一件之後（`sub_19202`）——動作由物品自己決定

```
選中編號 ＝ 裝備武器的彈藥（物品資料 +0x07）→ 141 `Reload?` → sub_196DB（§4）
附屬 byte bit7 設（那一格卡彈）        → 134 `Unjam?`  → sub_19ACD（§5）
其餘 → 142 `Do you want to:  Drop  Trade  Equip/unequip`：
  'D' 丟棄   sub_19AB6：那一槽兩個 byte 清 0（**不動裝備索引與 AC**）
  'E' 裝備   sub_1949E（§6）
  'T' 交給   §7
```

## 4. 裝填 `sub_196DB`（bl ＝ 彈匣槽位移）

```
武器附屬 byte bit7 設 → 印 152 `Your weapon is jammed.`，不裝
否則：彈匣那一槽整槽清 0（一次性，docs/re/107 同一條）
      武器附屬 ← (原值 & 0xC0) | 武器物品資料 +0x04（容量）
```

與戰鬥的 `L` 差別只在**彈匣是選中的那一件**，不是掃到的第一件。

## 5. 卸卡彈 `sub_19ACD`：一個藏在附屬 byte 低位的檢定

```
附屬 byte bit7 清 → 不卡，直接回
n ← 附屬 & 0x3F               ; **卡彈計數**（借用剩餘次數欄）
n ≥ 6 → 直接失敗
2d6 逢同點續擲 < 5 → 失敗      ; 與技能檢定同一個 fumble（docs/re/32 §3）
IQ（+0x0F）＋ 武器技能等級×3 ＋ 擲值 ≥ 5×n ＋ 15 → 成功
成功：印 160；**附屬 byte 整個清 0**（連彈藥一起沒了，要重新裝填）
失敗：印 161；卡彈計數 ＋1（`0x19B45` 上限判在 0x85）
```

門檻公式與技能檢定完全同形（`sub_19CAC` ＝ 5n＋15、`sub_19C84` ＝ 2d6 續擲、
`sub_19C69` ＝ 累加器比較——四支 helper 都是 `docs/re/32` 那一套）。

## 6. 裝備 `sub_1949E`（al ＝ 清單列號）

```
列號 ＝ +0x1F 或 +0x25 → sub_194E8 卸下（護甲那條順便把 +0x1A 的 AC 清 0）
物品類別（+0x03 >> 3，sub_199F1）＝ 15（護甲）：
    +0x1A（AC）← sub_19A0F（物品 +0x06 的骰數）；+0x25 ← 列號
其餘：+0x1F ← 列號
```

**`+0x25` ＝ 護甲的裝備索引**——`docs/re/15` 的欄位表可以補這一格。
remake 的 `Character.Equip` 先前已照這支實作，缺的是畫面入口與
`+0x25` 的存檔讀寫。

## 7. 交給隊友（`0x19299`）——NPC 會拒絕，隊友也會

```
人數 1 → 143 `No one to trade with.`
人數 2 → 對方 ＝ 自己 xor 3（1↔2，不用問）
否則   → 名單畫面 ＋ 144 `Who wants it?`（sub_1721B 選人，不能選自己）
給的人 +0x29 非 0 而且還能行動 → 拒絕檢定 sub_18288：
    v ← 給的人 +0x2E；0xFF → 一律拒絕
    2d6 續擲 < 5 → 拒絕
    收的人的魅力（+0x14）＋ 擲值 ≥ 5×v ＋ 15 → 成功，1/20 機率 v −1（下限 0）
    否則拒絕，v ＋1（上限 0x0A）
拒絕 → 印 135 ` doesn't want to trade.`
成功 → 收的人找空物品槽（滿了印 150）→ 兩個 byte 搬過去 → 原槽清 0
```

**`+0x2E` ＝ 交易難度計數**：拒絕會越拒越硬、成功偶爾軟化。
出廠 Ranger 的值是 0（門檻 15），所以自己人之間偶爾也會拒絕——
這不是 bug，是原版行為。倒下的人不會拒絕（`0x192EF` 的 CON 檢查）。

## 10. 這一輪學到的（寫成規則）

- **同一支函式在不同筆記裡可能只被看見一個側面。** `sub_19130` 在 `docs/re/129`
  只露出「金錢畫面」那一頁；把它的主迴圈讀完才知道是整個角色畫面。
  **遮罩表對到的函式值得整支讀完，不要只讀設定遮罩那三行。**
- **檢定框架認形狀就能省力。** `5n＋15`、`2d6 續擲`、`<5 fumble` 三件套
  一出現，剩下的只要找「加了哪些修正值」。
