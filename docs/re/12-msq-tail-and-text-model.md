# 12：MSQ 區塊的尾段與文字的分佈

日期：2026-08-13（§4 於 2026-08-14 依 `docs/re/17` 改寫）

## 1. 兩張長度表的差別解開了

`docs/re/06` 記過一個未解項：資源目錄旁有兩張長度表，數值不同。

| 表 | `ds:` 位移 | 語意 |
|---|---|---|
| `ds:BD86h` | 區塊**總長度** | 切區塊用（`docs/re/07`） |
| `ds:BD22h` | **讀取量** | 載入器實際讀進來、交給 XOR 解密的長度 |

差額就是**尾段**：

```
MSQ 區塊 ＝ [magic 4][checksum 2][XOR 加密段 …][Huffman 尾段 …]
                     └────── ds:BD22h ──────┘└─ 總長 − 讀取量 ─┘
```

例如 `game1` #0：總長 10,958、讀取量 8,583、尾段 2,375 bytes。

## 2. 尾段是無 magic 的 Huffman 流

尾段開頭是同樣的 8 bytes header，但第 5–7 bytes **不是 `msq`**：

```
game1 #0：00 10 00 00 | fe 49 00 00 | 11 d2 24 8e …
game1 #1：00 04 00 00 | f3 16 00 00 | 13 e0 52 13 …
```

前 4 bytes 是解壓後大小：`0x1000`（4,096）或 `0x400`（1,024）——
正是 `sub_1841F` 裡 `mov cx, 1000h` 的那個值。

沒有 magic 是因為載入器走的是 `sub_11AE8` 的 `AL=0` 路徑，
那條路徑在 `0x11B11` 直接跳過 magic 驗證。
**先前在解密後的區塊裡搜 `msq` 得到零命中，原因就是這個**——
零命中這次不是查法有洞，而是資料真的沒有 magic，兩者要靠程式碼分辨。

第 5–8 bytes 的用途未解。

## 3. 驗證：42／42

`tools/huffman.py`（加了 `verify_magic=False`）對全部 42 個區塊的尾段解壓：

| 檢查 | 結果 |
|---|---|
| 解壓成功 | **42／42** |
| 解出長度 ＝ 宣告大小 | **42／42**（`0x1000` 或 `0x400`） |

**尾段是地圖的第三層**：邊長 D 的正方形地圖，每格 1 byte，所以長度就是 D²
（D ＝ 32 → 1,024；D ＝ 64 → 4,096），42/42 吻合。載入位址 `ds:3448h`，
定址走 `sub_17FC8`。層的語意未解，結構與驗證見
**[`docs/re/24`](24-map-layers-and-tiles.md)**。

圖磚圖形不在這裡，在 `ALLHTDS1`／`ALLHTDS2`（一張 128 bytes、16 × 16 packed 4bpp）。

## 4. 敘述文字：在執行檔裡，是打包的

原版**有**長篇敘述文字，只是不以 ASCII 存放。執行檔內有九張
**5-bit 打包 ＋ 字元對照表**的字串表，合計 442 個字串，其中 `ds:D18Eh` 那張
是完整的結局敘述段落（`docs/re/17`）。

**掃 ASCII 找不到遊戲文字是正常的**——原版的文字管線本來就不用 ASCII 存放，
所以「最長字串只有 50 字元」這種統計不能拿來否定敘述文字的存在。

目前的分工：

| 來源 | 內容 | 狀態 |
|---|---|---|
| 執行檔的九張打包表 | 技能、物品、階級、疾病、介面訊息、結局敘述 | 已解（`docs/re/17`） |
| MSQ 區塊標頭 `+0x02` | 明文 NUL 分隔的敵人名表 | 已解（`docs/re/09` §3） |
| MSQ 區塊標頭第一個 word 指到的字串表 | 每個區塊各一張，合計 4,493 條敘述文字 | 已解（`docs/re/18`） |
| `paragraphs.txt` | 紙本段落書 162 段 | 已轉錄（`docs/paragraphs/`） |

**「遊戲只給編號、敘述全在紙本」這個模型不成立**：執行檔有 442 條、地圖區塊有 4,493 條，
合計 4,935 條遊戲內文字。段落書與遊戲內文字的分工要等段落呼叫表解出來才定案。

### 對重製版的意義

使用者已經定案「段落書內容要做進遊戲內手札」（`CLAUDE.md` §3.2），那個決定不受影響。
但**原版有自己的文字管線與控制碼**（`docs/re/14` §4.1、`docs/re/17` §4.5），
手札與遊戲內文字的呈現要以那套為準，不是全部自己設計。
