# 12：MSQ 區塊的尾段，以及「劇情文字不在遊戲裡」

日期：2026-08-13

## 1. 兩張長度表的差別解開了

`docs/re/06` 記過一個未解項：資源目錄旁有兩張長度表，數值不同。

| 表 | `ds:` 位移 | 語意 |
|---|---|---|
| `ds:BD86h` | 區塊**總長度** | 切區塊用（`docs/re/07`） |
| `ds:BD22h` | **讀取量** | 載入器實際讀進來、交給 XOR 解密的長度 |

差額就是**尾段**：

```
MSQ 區塊 ＝ [magic 4][checksum 2][XOR 加密段 …][Huffman 尾段 …]
                     └────── ds:BD22h ──────┘└─ 總長 − 讀取量 ─┘
```

例如 `game1` #0：總長 10,958、讀取量 8,583、尾段 2,375 bytes。

## 2. 尾段是無 magic 的 Huffman 流

尾段開頭是同樣的 8 bytes header，但第 5–7 bytes **不是 `msq`**：

```
game1 #0：00 10 00 00 | fe 49 00 00 | 11 d2 24 8e …
game1 #1：00 04 00 00 | f3 16 00 00 | 13 e0 52 13 …
```

前 4 bytes 是解壓後大小：`0x1000`（4,096）或 `0x400`（1,024）——
正是 `sub_1841F` 裡 `mov cx, 1000h` 的那個值。

沒有 magic 是因為載入器走的是 `sub_11AE8` 的 `AL=0` 路徑，
那條路徑在 `0x11B11` 直接跳過 magic 驗證。
**先前在解密後的區塊裡搜 `msq` 得到零命中，原因就是這個**——
零命中這次不是查法有洞，而是資料真的沒有 magic，兩者要靠程式碼分辨。

第 5–8 bytes 的用途未解。

## 3. 驗證：42／42

`tools/huffman.py`（加了 `verify_magic=False`）對全部 42 個區塊的尾段解壓：

| 檢查 | 結果 |
|---|---|
| 解壓成功 | **42／42** |
| 解出長度 ＝ 宣告大小 | **42／42**（`0x1000` 或 `0x400`） |

內容是大量重複的字母與小數值（`abbbbbabbbabbbab`、`FBFBFBFB`、`ZZZZZZZZ`），
形狀與 `ALLPICS` 的圖形區塊一致——**尾段是該地圖用的 tile 圖形**，不是文字。
（1,024 bytes ＝ 32 個 8×8 4bpp tile；4,096 ＝ 128 個。**這個換算還沒驗證**，只是尺寸相符。）

## 4. 遊戲檔案裡沒有長篇敘述文字

到這裡，原版所有資料檔的每一個 byte 都已經有歸屬：

| 來源 | 內容 |
|---|---|
| `GAME1`／`GAME2` 的 42 個 MSQ 區塊 | 地圖 2,048 ＋ 記錄表 ＋ 名稱字串 ＋ tile 圖形尾段 |
| `ALLPICS1`／`ALLPICS2` | 66／98 個子區塊，圖形與參數表交替 |
| `ALLHTDS1`／`ALLHTDS2` | 4／5 個大塊圖形 |
| `END.CPA` | 結局畫面 |
| `TITLE.PIC`／`COLORF.FNT`／`CURS`／`IC0_9.WLF`／`MASKS.WLF`／`TRANSTBL` | 開機載入的固定素材 |

**沒有一處是長篇敘述。** 另外掃過 `wl.exe` 的資料段：24 字元以上的字串只有 12 條，
最長的是 50 字元的 `A disk error has occurred. Please check the disks.`，
其餘都是 `YOU ARE NOT SMART ENOUGH!`、`Your life has ended in The Wasteland.` 這類短訊息。
搜 `paragraph`／`Read`／`manual` 之類的字樣是零命中。

這與原版的設計一致：**長篇敘述印在紙本段落書上**（`paragraphs.txt` 的 162 段），
遊戲只顯示編號要玩家去翻。這既是劇情載體，也是當年的防拷手段。

推論等級：**強證據**。所有資料檔都已解開且內容有歸屬、執行檔內無長字串，
兩邊互相支持；但還沒找到「顯示段落編號」的那段程式碼，找到才算完全確認。

### 對重製版的意義

使用者已經定案「段落書內容要做進遊戲內手札」（`CLAUDE.md` §3.2）。
這一節的結論支持那個決定，並補上一個約束：**原版沒有這些文字，所以沒有原版格式可以照抄**——
手札的資料結構、觸發時機、以及變體段落（`docs/paragraphs/` 標出的 64 段變體與 33 段火星誘餌）
要怎麼呈現，全部是重製版的設計決定，必須明確記成「remake 差異」而不是還原。
