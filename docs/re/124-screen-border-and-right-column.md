## 1. `sub_19814`：通用畫框

進來時游標（`ds:8DD0h`／`ds:8DD1h`）已經在**左上角**，
參數 `dl` ＝ 右下角的欄、`bl` ＝ 右下角的列。

```
0x19821  ds:CCDDh ← dl；ds:CCDEh ← bl；ds:CCDCh ← 目前的欄（左界）
0x1982F  ds:8DD9h ≠ 0 → ds:8DD1h ← 0Eh，跳過上緣   ; 局部重畫
         draw 0Eh                                   ; 左上角
         sub_19886：一直 draw 12h 直到欄 ＝ 右界      ; 上緣
         draw 0Fh                                   ; 右上角
loc_1984F（每一列）：
         欄 ← 左界；draw 0Dh                        ; 左直
         欄 ← 右界；draw 13h                        ; 右直
         列 ＋1，到 ds:CCDEh 為止
0x19872  欄 ← 左界；draw 10h                        ; 左下角
         sub_19886 → 12h 到右界                     ; 下緣
         draw 11h                                   ; 右下角
```

| 字模 | 位置 |
|---:|---|
| `0x0E` `0x12` `0x0F` | 左上／上緣／右上 |
| `0x0D` `0x13` | 左直／右直 |
| `0x10` `0x12` `0x11` | 左下／下緣／右下 |

⚠ `sub_10039` 印完會**自動右移一格**（`docs/re/04` §5），
所以橫線只要重複呼叫，而每畫完一列都要把欄重設回左界。

## 2. `sub_197BB`：地圖畫面的外框

呼叫端 `0x16226` 傳 `dl ＝ 0x25`（欄 37）、`bl ＝ 0x11`（列 17），
游標在 (0, 0)。畫完主框之後再補三處：

```
0x197CB  (0, 17)  ← 5Eh                 ; 左邊的 T 字接頭（蓋掉左下角）
0x197DA  (37, 17) ← 5Fh, 12h, 0Fh       ; 右邊的接頭 ＋ 欄 38、39
0x197F2  列 18–23：(0, 列) ← 0Dh、(39, 列) ← 13h
```

所以**訊息視窗那一段的外框是欄 0 與欄 39**，比上面那個框寬兩欄——
右邊那兩欄從列 0 到列 17 是計量表，列 18 以下才回到框線。

⚠ **列 24（指令列）沒有下緣。** 迴圈停在列 24（`cmp 8DD1h, 18h`），
畫面最底下那一列是指令列本身，不是框線。

## 4. `sub_166D3`：直排的 `WASTELAND`

```
0x166D3  ds:8DD9h ≠ 0 → retn            ; 局部重畫時不畫
0x166DA  ds:4680h ← 0AA4Dh              ; 資料指標
0x166E0  游標 ← (0x26, 0)
loc_166EA：
  al ← [ptr]；＝ 0 → 收工                ; **0 是結束標記**
  ptr＋1；draw；al ← [ptr]；ptr＋1；draw  ; 一列兩格
  欄 ← 0x26；列 ＋1
```

`ds:AA4Dh` 的內容（檔案位移 `0x1791D`）：

```
62 63 | 64 65 | 66 67 | 68 69 | 6a 6b | 6c 6d | 64 65 | 6e 6f | 70 71 | 00
```

九列、每列兩個彩色字型的字模（一列一個字母，字母是 16 × 8 的兩格拼起來），
`0x62`–`0x71` 共 16 個。**第 2 列與第 7 列是同一對 `0x64 0x65`**——
那正是 `WASTELAND` 的兩個 `A`。

⚠ 這一欄與輻射沒有關係，是**遊戲名**。實機截圖
（`workplace/dosbox/shots/20-map.png`）右邊那一直行由上往下讀就是
`W A S T E L A N D`，底下才接輻射計量表。

推論等級：§1–§4 全部**已確認**。

## 6. 這一輪學到的（寫成規則）

- **「重複的字母在第幾個」是驗字串最快的檢查，但要先確定在驗哪一個字。**
  這張表第 2 列與第 7 列相同，拿 `RADIATION` 去對會得到「不是文字」的結論，
  拿 `WASTELAND` 去對第一次就中。**心裡先有一個候選字，再去數重複位置**——
  否則這個便宜的檢查會給出一個很有說服力的錯答案。
- **把字畫出來比推論快。** 這一欄的身分是實作完跑一次截圖確定的，
  九個字母當場就讀得出來。**能畫出來的東西不要用推的**。
- **畫框的常式通常只有一支。** 找到 `sub_19814` 之後，
  設施、清單、訊息視窗那幾個框都是同一支的呼叫端——
  逐個畫面去讀它們各自的框是白費力氣。
