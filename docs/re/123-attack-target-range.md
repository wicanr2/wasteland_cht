## 1. `sub_122E9`：這一組算不算數

它走遭遇佇列（`ds:46C8h`，每筆 `+0` ＝ x、`+1` ＝ y、`+2` ＝ 資源），
四個條件全過才回報一組：

```
0x122E9  [+2] ≠ ds:4655h → 跳過            ; **不在目前這張地圖**
0x122F7  [+0] ＝ 0 → 跳過                   ; 空槽
0x1230D  call sub_19D4D                     ; 距離 ＝ ds:CD0Dh[10·|Δy| ＋ |Δx|]
0x12310  cmp al, ds:46CCh ; cmc ; lahf       ; **距離 ≥ 接戰值 → 跳過**
0x12328  call sub_169CF                      ; **座標在不在 19 × 9 的地圖視窗內**
0x1232B  jb 跳過
0x1232D  sub_13787；比 ds:46C6h 的記錄 +0x00 ; 那一格還有沒有敵人
0x12347  call loc_14330
0x1234A  回傳 ds:0A427h
```

兩個呼叫端：

| 呼叫端 | 做什麼 |
|---|---|
| `0x12293`（`sub_12284`）| 畫「Which group?」清單的**一列**；這一支回 CF ＝ 1 那一列就是空的 |
| `0x1383F`（`sub_13828`）| 雇用的候選掃描 |

## 2. 接戰值 `ds:46CCh` ＝ 距離上限，由武器決定

`sub_13878(al ＝ 角色編號)`：

```
0x13878  sub_172BB → CON ≤ 0 → ds:46CCh ← 0        ; 不能行動
0x13886  ds:46CCh ← 0Fh                            ; 預設近戰
0x1388B  sub_196B2 → 裝備武器那一格的物品資料
0x1388E  sub_199F1 → 物品資料 +0x03 ＝ 類別；0 → 沒武器，維持 0Fh
0x13896  sub_19D2F → 類別在 ds:CD00h 的射程清單裡才繼續
0x1389B  ds:46CCh ← 0FEh                           ; 有射程
0x138A9  sub_138C1 → 彈匣裡的發數（物品槽附屬 byte 低 6 位）＝ 0
                    → sub_1391E → **ds:46CCh 壓回 0Fh**
```

| 接戰值 | 什麼時候 |
|---:|---|
| `0x00` | CON ≤ 0（不能行動）|
| `0x0F` | 能行動：沒武器、近戰武器，**或有射程的武器但彈匣空了** |
| `0xFE` | 有射程的武器**而且還有子彈** |

距離表的值是 10 × 歐氏距離（`docs/re/37` §4），所以 `0x0F` ＝ 15
換算過來只有一格半——**拿刀的隊伍打不到隔幾格的敵人，得先走過去**。
`0xFE` 幾乎等於無限制。

⚠ **「有射程」不只看武器種類，還要有子彈。** 少了 `sub_138C1` 那一步，
空彈匣的槍照樣打得到遠處的敵人，而畫面上完全看不出來。

## 3. 「Which group?」清單：攻擊與雇用共用

```
0x12262  ds:469Dh ← 組數 ＋1
0x12267  al ← 3Fh ; sub_16CB2        ; 印字串表 1 第 63 條 `Which group?`
0x1226C  ds:469Ch ← 'A'              ; 熱鍵從 A 起
0x1227B  ds:4696h ← 2284h            ; **每一列的畫法 ＝ sub_12284**
0x12281  jmp sub_16DB4               ; 清單元件（docs/re/117 §2.2）
```

兩個呼叫端：`0x121C7`（攻擊指令那一路 `sub_121A8`）與 `0x12383`（雇用）。
每一列都要先過 §1 那四個條件，過不了就是空的一列——**選不到，也就打不到**。

## 4. 「No one is within range.」是**雇用**印的

```
0x1236F  ds:46CCh ← 0FFh
0x12375  call loc_1382B          ; 遭遇裡「數量欄非 0」的組數（docs/re/110）
0x12378  ＝ 0 →
0x1237C  al ← 39h ; call sub_16CB2   ; 字串表 1 第 57 條
0x12383  否則 → sub_12262（開清單）
```

字串表 1 第 57 條是 `\x04No one is within range.\r\x06`。
⚠ **它不在攻擊那條路上。** 攻擊沒有這句話——清單列不出東西時，
玩家看到的是一份空清單，不是一句解釋。

## 5. 對攻略 M-14 的結論

> 敵人的像沒出現就無法攻擊；解法是用 `RUN` 指令往前移動直到它出現

**相符**，而且兩件事共用同一批條件：肖像框畫的是遭遇佇列裡最近的一組
（`docs/re/115`），而「Which group?」清單的每一列也是從同一個佇列篩，
篩掉的條件包含**距離 ≥ 接戰值**與**座標不在 19 × 9 的地圖視窗內**。
所以「像沒出現」與「打不到」是同一批條件的兩個出口。
`RUN` 往前走同時把敵人拉進視窗、把距離壓到接戰值以下——
攻略給的解法正好對上機制。

推論等級：§1–§4 全部**已確認**。

## 8. 這一輪學到的（寫成規則）

- **「哪一句話是誰印的」要查呼叫端，不要靠語意猜。**
  `No one is within range.` 聽起來像攻擊打不到，實際上印在雇用那條路上。
  猜錯的代價是把一道閘接到錯的指令上。
- **「畫面上看不到就做不到」在老遊戲裡常常是字面成立的。**
  視窗的 19 × 9 不只是顯示範圍，它是**規則的一部分**（`sub_169CF` 被規則層呼叫）。
  重製時把視窗當成純呈現，會安靜地放寬玩法。
- **能力值的上限常常還有一個「耗材」條件。** 接戰值 `0xFE` 看起來由武器種類決定，
  真正的最後一步是「彈匣裡還有沒有子彈」。**解完一條路要把收尾那幾行讀完**——
  `sub_138C1` 的出口就是把剛設好的值壓回去。
