## 1. 三個條件，全過才算一個目標

`sub_122E9` 走遭遇佇列（`ds:46C8h`，每筆 `+0` ＝ x、`+1` ＝ y、`+2` ＝ 資源）：

```
0x122E9  [+2] ≠ ds:4655h → 跳過            ; **不在目前這張地圖**
0x122F7  [+0] ＝ 0 → 跳過                   ; 空槽
0x1230D  call sub_19D4D                     ; 距離 ＝ ds:CD0Dh[10·|Δy| ＋ |Δx|]
0x12310  cmp al, ds:46CCh ; cmc ; lahf       ; **距離 ≥ 接戰值 → 跳過**
0x12328  call sub_169CF                      ; **座標在不在 19 × 9 的地圖視窗內**
0x1232B  jb 跳過
0x1232D  sub_13787；比 ds:46C6h 的記錄 +0x00
0x12347  call loc_14330
0x1234A  回傳 ds:0A427h
```

`ds:46CCh` 是**接戰值**（`docs/re/39` §4）：不能行動 0、能行動 `0x0F`、
能行動且射程條件成立 `0xFE`。挑目標之前先設成 `0xFF`（`0x12371`），
掃的過程把它壓成目前最近的距離——**與肖像框那一支（`sub_12636`）同一個手法**。

## 2. 一組都沒有 → 「No one is within range.」

```
0x1236F  ds:46CCh ← 0FFh
0x12375  call loc_1382B          ; 遭遇裡「數量欄非 0」的組數（docs/re/110）
0x12378  ＝ 0 →
0x1237C  al ← 39h ; call sub_16CB2   ; **執行檔字串表 1 第 57 條**
```

字串表 1 第 57 條就是 `\x04No one is within range.\r\x06`。

## 3. 對攻略 M-14 的結論

> 敵人的像沒出現就無法攻擊；解法是用 `RUN` 指令往前移動直到它出現

**相符**，而且兩件事共用同一批條件：肖像框畫的是佇列裡最近的一組
（`docs/re/115`），能不能打也是從同一個佇列篩，篩掉的條件包含
**「座標不在 19 × 9 的地圖視窗內」**。所以「像沒出現」與「打不到」
在原版是同一個謂詞的兩個出口。`RUN` 往前走會把敵人拉進視窗、
把距離壓到接戰值以下——攻略給的解法正好對上機制。

## 6. 這一輪學到的（寫成規則）

- **「畫面上看不到就做不到」在老遊戲裡常常是字面成立的。**
  視窗的 19 × 9 不只是顯示範圍，它是**規則的一部分**（`sub_169CF` 被規則層呼叫）。
  重製時把視窗當成純呈現，會安靜地放寬玩法。
- **訊息字串是找閘門最快的路。** 「哪裡擋住我」查不到時，
  先在字串表找那句話，再查誰印它——這一份的入口就是這樣找到的。
