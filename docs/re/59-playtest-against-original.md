# 59：正常玩家路徑對原版驗收（第一輪）

日期：2026-08-15 ｜ 對應 `CLAUDE.md` §4「驗收要對原版行為，不是只跑單元測試」

輸入：`wl.merged.exe` 與原版資料的 SHA-256 見 `docs/re/01`；
實機環境見 `docs/re/47`。

26 份規格全部 READY 並實作、單元測試全綠——但**那證明不了玩得通**。
這一份記錄第一次「照玩家會走的路跑一遍」找到什麼。

---

## 1. 工具：`cmd/wl-play`

無頭的腳本驅動器，把輸入一步一步餵給 `play.Scene` 並印出狀態：

```bash
tools/go.sh run ./cmd/wl-play -script "up,x40,left,x40,down,x40" -trace
  22 up       (55, 40) 02:28 地圖 活著 4/4｜The ground seems to glow here. (44 damage)
  23 up       (55, 39) 02:32 地圖 活著 3/4｜The ground seems to glow here. (72 damage)
  24 up       (55, 38) 02:36 地圖 活著 0/4｜The ground seems to glow here. (57 damage)
```

一行狀態摘要（座標、時鐘、模式、活著幾人、訊息）就足以看出走到哪裡出事。
`-stop-on` 讓某段訊息出現時回非 0，可以掛進 CI。

## 2. 找到的三件事

### 2.1 走進輻射帶兩步全隊倒地 —— **這是原版行為，不是 bug**

第一反應是實作錯了：資源 0 的輻射帶有 36 格連續，走不過去等於地圖被切斷。
拿原版驗（`tools/dosbox.sh`，開場 → `P` → 往北 24 步）：

```
畫面：Grim Reaper 的骷髏肖像
訊息：The ground seems to glow here.（三行）
時鐘：02:40
```

**原版一樣是走幾步就死。** 起始四人的 CON 是 28／27／34／31、AC 全 0
（角色選單畫面直接讀得到），而輻射一步扣 3–5 顆 d6，兩步就超過。

**差點把正確的實作改掉。** 記在這裡是因為下一個人會有同樣的直覺。

### 2.2 Rad suit 才是解答（順帶修正 `docs/re/55`）

追「原版怎麼可能讓玩家過去」時把 `0x14410` 那個沒讀懂的比較解開了：

```
0x14423  call sub_196C4      ; bl ← 護甲槽（+0x25）指到的物品陣列位移
0x14426  bl ＝ 0 → 沒穿護甲，直接受傷
0x1442C  al ← 角色記錄[bl]   ; 護甲的**物品編號**
0x14432  cmp al, 29h         ; ＝ 41 → 跳過這個人
```

物品表第 41 筆就叫 **`Rad suit`**（`docs/re/generated/ida94/items.md`）。
**穿著它的人完全不受輻射影響**——不扣血也不中毒。

`docs/re/55` §5 原本把這個比較寫成「拿角色記錄 `+0x01` 比 `0x29`，用意未解」，
那是把 `bl` 當成了 1。正解是 `sub_196C4` 先把 `bl` 設成護甲槽位移。

順帶排除另一條路：nibble 9 的收尾 `jmp sub_169B1` → `sub_17CFF` 是**改寫地圖格**，
但 211 個輻射格的記錄 `+0x02` **全部是 `0xFF`**（bit7 設 ＝ 不改），
所以踩過不會變成普通地形，每一步都會結算。

### 2.3 每一局的遭遇序列完全相同 —— 真的缺一塊

同一串 200 步跑三次，結果一模一樣。原因不是 bug 而是**沒實作**：
產生器沒有種子（初值全零，`docs/re/13`），熵來自**鍵盤輪詢次數**
（`sub_18EFE` 每輪詢一次就推進一次）。

規格 02 §1.1 早就寫了「這個行為要照做」，但呈現層沒有做。
補上 `Scene.PollRNG()`，`internal/ui` 每幀叫一次——
與原版同一個機制（玩家花多久按鍵就是熵）。

⚠ **無頭工具刻意不叫**：`wl-shot` 與 `wl-play` 保持決定性，
不然對拍與回歸測試會每次不同。

## 3. 這一輪學到的（寫成規則）

- **「這個行為不合理」要先問原版怎麼做，不要先改程式。** 輻射帶兩步團滅
  看起來像傷害公式爆掉，實機一跑就知道原版也這樣。
  **對原版驗收的意義就在這裡：它同時擋住假 bug 與真 bug。**
- **玩不下去的地方會指向沒讀懂的程式碼。** 追「原版怎麼過輻射帶」
  直接把 `cmp al, 29h` 解開了——那個比較我在 `docs/re/55` 標成未解，
  是因為只讀了那三行、沒追 `bl` 從哪來。
  **卡在遊戲性上的問題，答案常常在 RE 那一側。**
- **決定性的測試結果本身是一種症狀。** 三次跑一模一樣當下看起來是好事
  （可重現），實際上是熵沒接上。**跑很多次得到同一個答案，
  要先確認「本來就該不一樣」。**

## 4. 可重跑的完整指令

```bash
# remake 這一側
tools/go.sh run ./cmd/wl-play -script "@55:40,up,up,up" -trace

# 原版這一側：開場 → P 進遊戲 → 往北 24 步
tools/dosbox.sh "wait:6;key:Return;wait:4;key:p;wait:5;shot:rad10;\
$(python3 -c "print(';'.join(['key:Up','wait:1']*24))");wait:2;shot:rad11"
```
