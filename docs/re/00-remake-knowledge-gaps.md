# 00：Remake 知識缺口盤點

日期：2026-08-14 ｜ 這份是 **RE 完成度的單一檢查表**。
`CLAUDE.md` 的閘門規定「規格 READY 才能寫引擎」，而這份表回答的是
**「還差哪些規格」**。每一列都要走到「已確認」才算 RE 完成。

進度：IDA 自動辨識 **641** 個函式，人寫的筆記涵蓋 **213** 個，**428 個尚未碰過**
（`00-function-index.md`）。資料格式、文字與資產層大致打通，**世界互動層是目前最大的缺口**。

推論等級：`已確認`／`強證據`／`假說`／`未解`。

## 下一步的優先序

依「對 remake 的阻擋程度」排：

1. **E1／E2 移動、時間與觸發條件** —— 記錄容器（A6）與效果系統（E5）都解了，
   缺的是「玩家踩到什麼會啟動哪一筆記錄」。
2. **B6 畫面版面** —— 現在擋住畫面重現的是視窗幾何：畫一格的路徑（`sub_1029B`
   ＋ 列位址表）與整塊搬移的路徑（`sub_10F12`）還沒對上（`docs/re/24` §5）。
3. **C2 存檔欄位** —— 角色記錄（C3）已解，存檔是它的外層容器。
4. **E3 段落編號** —— 擋住手札設計的定案。
5. **A9 的參數區** —— 圖片本身已解，剩下交錯的動畫參數表（`sub_10A7A`）。

已完成：**D7 亂數產生器**（`docs/re/13`）、**A11／A15／A16 字型與文字編碼**（`docs/re/14`）、
