# 精訊電腦 第 27 期（1988 年 12 月）——〈遊騎兵手記〉之一

作者「銀狐」，刊在「遊戲攻略篇」，標題是一副對聯：

> 傲嘯荒漠　遊俠仗義江湖行
> 浮萍半生　神鎗漂泊走天涯

這是目前找得到**最早的中文《Wasteland》攻略**：1988 年 12 月，
與美國原版同年；比軟體世界那篇（1990，`docs/walkthrough/swm-005/`）早了一年半，
而且寫的是 **Apple II 版**——本專案逆向的 DOS 版是同一款遊戲的另一個平台版本。

體例也完全不同。軟體世界那篇是第三人稱的通關指南；這一篇是**第一人稱的手記**，
以隊上繪圖員 Fox 的口吻寫成，四個人物有名字、有個性，遇敵、談判、賭博、
甚至隊友差點被怪物當午餐都寫進去。攻略資訊藏在敘事裡，讀起來像小說。

## 為什麼這一篇值得保存

**它保留了另一套譯名。** 軟體世界把 Ranger 譯成「遊俠」，這一篇譯成「遊騎兵」；
遊戲名在標題聯裡是「荒漠」，而 1990 年的代理版封面寫「荒野遊俠」。
同一款遊戲在台灣的兩個時間點、兩本雜誌、兩種叫法，兩種都留著。

**它記錄了 Apple II 磁片版的玩法。** 〈江湖經驗〉那三條——換資料片重來、
靠換片無限刷 Gas Mask 賣錢、`Ctrl-R` 重排技能與物品——都是磁片時代的操作，
DOS 版沒有「四張資料片」這回事。這是版本差異的一手證據，不是攻略作者記錯。

**它的地圖是手繪的。** 五頁裡有六張圖：世界地圖與 Highpool、農業中心、
沙漠遊牧民族、礦坑、Quartz 與酒吧的樓層圖，全部是作者自己畫的點陣圖與手寫標註。
本目錄把圖上的標註逐一轉成文字表（見各頁），圖本身連到來源網站。

## 體例

- **逐頁完整轉錄**，保留 1988 年的用字、標點與英文原名的夾用方式
  （原文中英夾雜，英文一律照原樣）。
- 原文的排印錯誤照樣轉錄，另加註記說明，不直接改成正確答案。
  例：`Roof Caveln`（原文如此，應為 `Cave-in`）、`Sante Fe`／`Santa Fe`
  同一頁兩種寫法。
- 讀不清的字寫 `〔字跡不清〕`，不猜一個填上。
- 手繪地圖的標註轉成表格，位置用「圖上相對位置」描述。
- **掃描件不入版控**（與軟體世界那份同一個政策）：圖連到來源網站，
  本目錄只放轉錄與對照。
