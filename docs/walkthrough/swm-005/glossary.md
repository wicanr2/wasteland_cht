# 軟體世界第 5 期的用語與譯名

這一份記錄的是**當年的選字**，不是本專案的定譯。兩者刻意分開：
專案的定譯在 [`translations/glossary.md`](../../../translations/glossary.md)，
那是 remake 實際會用的；這裡是 1990 年前後台灣雜誌怎麼稱呼這些東西的紀錄。

有些詞當年就直接沿用英文（`Bloodstaff`、`Rad Suit`、`LAW`），
有些音譯（史派德賭場、諾曼人），有些意譯（蕈狀雲教、血神殿），
還有些借用了當時的流行文化（機械戰警）。這個分佈本身就是史料。
