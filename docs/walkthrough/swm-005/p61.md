# p.61 — 下水道之旅與 Max 的組裝

來源：軟體世界第 5 期 p.61（`62.jpeg`）

## 圖十五：VEGAS, Sewers

左欄中段的手繪地圖，圖說編號「圖十五」，圖框下緣印英文圖名 `VEGAS, Sewers`。
畫面是縱長形的迷宮，通道以白色細線構成、大量分岔，中央偏左有一條縱貫的水道帶。

標註點與相對位置：

| 標註 | 圖上位置 | 手寫原文 |
|---|---|---|
| 入口 | 圖框外左下方，有箭頭指入 | 中文標註 |
| 組合室 | 圖框外右上方，有箭頭指入右上 | 中文標註 |
| `Use Shovel` | 中央偏右，數處 | 手寫英文，標在可挖開的碎牆位置 |
| 〔零件位置符號〕 | 散佈圖中數處 | 圖中另有數個小符號，依內文所述為攜帶零件的機械人位置 |

原文明說地圖上標了**攜帶零件的機械人大概位置**，讀者可以直接去收零件、
不必打無用的仗。這些位置只存在於圖上，沒有以文字寫出。

## 內容

（承 [p.60](p60.md)）原子爐右方房間的密門打開後，隊伍一路往上，
從**左上角的入口**進入下水道。

### 下水道概況

作者形容 Vegas 的下水道「大得不太像話」，而且**似乎是殺人機器的大本營**。

### 難題一：渡過水道

第一個難題是如何渡過湍急的水道。解法：

> 幸好 L.I.V 身上還有根繩子，搭一道繩橋（站在水道岸邊，向下使用繩子即可）便過去了

〔機制斷言〕繩子作為道具使用、需要面向正確方向——見
[`mechanics-claims.md`](mechanics-claims.md) M-28。

### 難題二：敲起來空洞的牆

有些地方可以找到**敲起來空洞的牆**（圖上**標有 `Use Shovel` 之處的碎牆**），
正好用當初在諾曼人營地挖寶的**鏟子**（`Shovel`）挖開。
處理完之後整個下水道就通行無阻了。

〔機制斷言〕特定牆面要用鏟子挖開才能通過——見 M-29。
〔對照〕原文此句作「如此整個徙水道便可通行無阻了」，「徙」應為「條」或「下」之誤植。
照原樣記，不改。

### 殺人機器與零件

四處和殺人機器對戰的結果，是得到一些**能量武器**、**能源包**，
以及四種用途不明的裝備：

| 零件 | 原文英文 |
|---|---|
| 伺服馬達 | `Sever motor` |
| 融合爐 | `Fusion Cell` |
| 電路板 | `Rom board` |
| 能源轉換器 | `Power Conventer` |

〔對照〕`Sever motor` 應為 `Servo motor`，`Power Conventer` 應為 `Power Converter`。
兩處都是原文的拼寫，照原樣記，不改。

作者本來不相信 Max 是個機械人，但從散佈四處的零件和**一個機械頭部**看來，
Charmaine 所言不虛。

原文註記：

> 註：地圖上標有攜帶該零件的機械人大概位置，各位只需直接收集這些零件，不必多打無用的仗。
> 此外，小心 Cyborg 和 Hexborg 這兩種敵人

〔機制斷言〕`Cyborg` 與 `Hexborg` 是下水道中特別危險的敵人——見 M-30。

### 組合室

最後抵達**右下角的一個房間**。房門**沒辦法炸開**，作者想到用**音波鑰匙**
（p.60 從蠍式身上取得）來試，果然應聲而開。

進去拿到**最後一塊電路板**之後，看到房間右側放著**一排四個組合桌**，
用來組合機械人。

〔機制斷言〕音波鑰匙開啟爆破無效的門——見 M-20。

### Max 的組裝步驟（重要）

原文以註記的形式給出簡化過的操作序列。先說明編號方式：

> 走到組合桌上，由上而下是為 (1)、(2)、(3)、(4)

四張桌子的操作：

| 桌 | 操作序列 |
|---|---|
| (1) | 選 (2) → 原地使用 `Android Head` → 選 (2) → 原地使用電路板 → 移動至 (2) |
| (2) | 選 (2) → 原地使用融合爐 → 選 (2) → 原地使用能源轉換器 → 選 (2) → 原地使用伺服馬達 → 選 (2) → 原地使用電路板 → 選 (2) → 移動至 (3) |
| (3) | 選 (2) → 原地使用伺服馬達 → 選 (2) → 移動至 (4) |
| (4) | 選 (2) → 原地使用伺服馬達 → 選 (2) → 原地使用伺服馬達 → 選 (2) |

完成後：

> 分別到 (1)(2)(3)(4)，各選 (3) 即可

零件用量小計（依上表）：

| 零件 | 次數 |
|---|---|
| `Android Head` | 1 |
| 電路板（`Rom board`） | 2 |
| 融合爐（`Fusion Cell`） | 1 |
| 能源轉換器（`Power Conventer`） | 1 |
| 伺服馬達（`Sever motor`） | 4 |

〔機制斷言〕組裝流程中的「選 (2)」「選 (3)」是選單項次，
`(2)` 疑為「使用／放置」、`(3)` 疑為「組裝／完成」。
原文沒有寫出選單的文字，只給編號——這一點要和逆向出來的選單對照，見 M-31。

### 結尾

四個部份組合起來後，**Max 復活了**。他告訴隊伍有關 **Sleeper Base** 和
**Darwin Village** 的事，並要隊伍**從下方的門離開**。

全文以一句留白收尾：

> 望著無垠的沙漠，我們坐下來休息一會兒。不知道我們的旅程還有多久才會結束？
