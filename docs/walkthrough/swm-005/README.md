## 體例

這幾份文件記錄的是**攻略內容**：路線、地圖、答案、道具、以及作者對遊戲規則的敘述。
組織方式是本專案自己的，不是原文的逐字翻印；當年的用字本身就是史料的地方
（譯名、術語、對機制的稱呼、明顯的口語腔調）以引號標出原句或原詞。

沿用的規則：

- **當年的譯名與術語照留**，不換成現代說法，也不換成本專案 `translations/glossary.md` 的定案譯名。
  「沙漠傳奇」「荒野遊俠」「蕈狀雲教」「史派德賭場」「機械戰警」「蠍式殺人機器」
  都是那個年代的選字，換掉就沒有保存的意義了。
- **隊員名照原樣寫成 `G.R.X`／`L.Y.C`／`L.I.V`** 這種縮寫格式（原文的空點排版不統一，
  有時作 `L.I.V`、有時作 `L.I.V.`，這裡一律簡化為前者）。
- **與原版遊戲不一致之處照原樣記，另加註記說明差異**，不直接改成正確答案。
  這類地方標成 `〔對照〕`。
- 掃描件上判讀不出來的字標 `〔字跡不清〕`，不猜。
- 手繪地圖不重繪，改用**文字描述加表格**交代它標了哪些點、標在哪個相對位置，
  並保留「圖十」到「圖十五」的原編號。

## 與本目錄之外的攻略是什麼關係

`docs/walkthrough/` 底下那八章是從 `game1`／`game2` 的資料檔倒出來的，
是機器讀出來的事實。這一份不是——**它是 1990 年前後一位玩家的實際遊玩紀錄**，
會有記錯、聽錯、拼錯，也會有只有玩過才知道的操作細節。

兩者的定位因此不同，`CLAUDE.md` §5 的 oracle 優先序裡，社群攻略排在最後：

> 原版執行檔行為（IDA 讀出） > DOSBox 實跑觀察 > 官方英文手冊 >
> 軟體世界中文說明書 > 社群攻略

所以這份東西**不能拿來當規格的依據**。它的用途有兩個：

1. **保存**：當年台灣玩家的用語與理解方式。
2. **線索**：文中對機制的具體斷言（技能等級門檻、雇用 NPC 的條件、隱形敵人怎麼打）
   可以拿去和 `docs/re/` 的逆向結果對照——**對照的方向是拿逆向結果去驗證它，
   不是拿它去修正逆向結果**。

這些斷言整理在 [`mechanics-claims.md`](mechanics-claims.md)，一條一條標了要去查哪份筆記。

## 這篇攻略在連載中的位置

第 5 期這六頁從 Quartz 的幫派藏身處開始，到 Vegas 下水道把 Max 組裝起來為止，
結尾寫「不知道我們的旅程還有多久才會結束？」，明顯是連載的中段——
前面應該還有至少一期講建隊、Highpool、農業中心與 Quartz 前半，
後面則還沒碰到 Darwin、Sleeper Base 與 Guardian Citadel。本專案目前只取得第 5 期這六頁。
