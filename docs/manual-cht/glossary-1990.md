# 當年譯名對照表

取自 1990 年代軟體世界《荒野遊俠》中文說明書。左欄是說明書實際使用的中文寫法，中欄是說明書上印出的英文，右欄是英文原版的正確拼法（僅在說明書印錯時填寫）。

說明書的體例是「英文原文保留、中文只譯通用名詞」：屬性、技能、指令、狀態、武器類型有中文譯名；人名、地名、組織名、物品專名幾乎全部保留英文，僅少數（血杖、血神殿、蕈狀雲、沙漠流浪者、流浪者中心）有中譯。
