# 荒野遊俠（Wasteland）軟體世界中文說明書

1990 年代台灣「軟體世界」（SOFT-WORLD RESEARCH CENTRE，高雄）代理發行的《Wasteland》中文版說明書逐頁轉錄。中文譯名為「荒野遊俠」。

轉錄以保存為目的：譯名、術語選字、行文語氣、錯字誤植、前後不一致之處全部照原樣保留，不以英文原版或現代用語修訂。與英文原版有出入之處以引言區塊加註，正文不動。

## 頁碼與掃描檔對應

主說明書每張掃描檔是一組對開兩頁：`wlNN.jpg` 對應第 `2N-1`、`2N` 頁。`wl00.jpg` 是封面。`wl25.jpg` 之後不再是說明書內頁。

| 掃描檔 | 內容 |
|---|---|
| wl00 | 封面 |
| wl01 – wl24 | 說明書第 1–48 頁 |
| wl25 | 封底廣告頁（《威探闖通關》）＋封底 |
| wl26 | CD 盒背面文案 |
| wl27 – wl30 | IBM 版補充說明書第 1–6 頁（wl27、wl29 為對開兩頁，wl28、wl30 為單頁） |
| wl31 – wl32 | 磁片與外套（Disk1、Master Disk 2） |

## 轉錄體例

- 一張掃描檔的兩頁各自成一小節，標題格式為 `## wlNN（第 N 頁）`。
- 插圖與遊戲截圖以 `〔…〕` 一行說明標註；截圖中的英文字幕以程式碼區塊照抄。
- 掃描辨識不出的字寫 `〔字跡不清〕`，整段不可辨識寫 `〔本段掃描不清〕`。
- 與英文原版不一致或說明書自身前後矛盾之處，以 `> 註：` 引言區塊說明，正文維持原樣。

## 掃描品質與缺漏

- 全書解析度偏低（對開兩頁約 1050×525 像素，單頁約 525×525）。小字號的遊戲截圖數值（隊伍列表的 AC／ARM／MAX／CON 欄）辨識不確定，已在對應位置註明。
- 第 48 頁（wl24 右半）整頁灰白，僅見背面透印輪廓，無可辨識內容；位置對應封底內頁，推測本為空白頁。
- 說明書正文 1–47 頁連續，無缺頁；劇本 001–162 段編號連續，但第 30 頁末一段編號誤印為 `050`（與同頁稍前的 050 重複），依內容與次頁銜接應為 055。
- 說明書正文的頁眉：左頁「・荒野遊俠・」、右頁「・軟體世界・」，全書一致。
- IBM 版補充說明書為另一本黃色小冊，另行編頁 1–6，內容為 IBM PC 版流程；主說明書描述的是 Apple II 版流程（雙面磁片、按 `S`／`U` 進入），兩者不通用。
