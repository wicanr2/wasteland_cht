## wl01（第 1 頁）

〔頁眉左：・荒野遊俠・〕

### 一、故事介紹

　　緊張的局勢隨 1998 年的來臨而不斷昇高。美國的“城堡”星站已完全由軍方接管，蘇聯譴責美國這項舉動會引起第三世界的恐慌。在毒品戰爭（1987-1993）期間，經美國協助而成立的中南美右派政府，紛紛表示支持美國。北約國家組織，包括非洲新興的人民團體在內，也宣佈與美國結盟。這種情勢，迫使其餘的中立勢力加入蘇聯的反對陣營。在短短六週內，只剩下瑞士、瑞典和冰島還保持中立國的身份。

　　當“城堡”正式啟用的兩週前，傳來一個不幸的訊息。就在訊息發出的同時，突然大部份的衛星在空中消失，脫離地球的引力圈。在驚慌中，美蘇雙方將 90％ 的核子武器射向天空。這場毀滅相當劇烈，但不徹底。仍有許多文明地區殘存下來，有些甚至在大戰中毫髮未損。

　　在美蘇彼此都想毀滅對方的那天，一群美國陸軍的工程師正在西南部的沙漠中建造橋樑，他們在荒涼的山谷中工作，周遭都是倖免於難的難民。在他們所在位置的正南方是座剛蓋好的聯邦監獄。那裏除了監禁死刑犯的囚牢外，監獄裏還有輕工業的生產設備。

〔插圖：沙漠中的橋樑工程與遠方的核爆蕈狀雲、輸電鐵塔〕

　　當核子攻擊開始後，這群急於找尋避難所的工程師接管了監獄。並把犯人趕到荒涼的沙漠中。幾星期後，他們邀集鄰近的難民加入，並齊力重建新社會。由於人們彼此猜忌，起初這項工作進行並不順利，但時間鞏固了彼此的信賴。最後這些難民以 Ranger Center 為名，成為最強大的殖民區之一。流浪者中心的堅強實力，可從他們擊退那些企圖奪回聯邦監獄的死刑犯得到證明。

### 二、進入遊戲

　　荒野遊俠磁片共分兩片四面，分別標明 Boot 及 2.3.4. 面資料片。初次玩此遊戲的人，請依下列步驟先備份磁片。以後再玩該遊戲只要執行載入遊戲步驟即可。

#### (A) 備份磁片

(1)將 Boot 面放入磁碟機，開機後出現如下畫面：

〔遊戲截圖：星空中的行星，下方字幕〕

```
        Electronic Arts and
Interplay Productions proudly present
              WASTELAND
 Copyright 1986,87 Interplay Productions
Start Utils            Written by Alan Pavlish
```

## wl02（第 3 頁）

〔頁眉左：・荒野遊俠・〕

(2)按 `U`（Utilies）鍵進入公用程式

> 註：原文拼作 `Utilies`，英文原版為 `Utilities`，照原樣轉錄。

(3)按 `C`（Copy），螢幕上方會問你用幾台磁碟機複製備份磁片，依照你硬體配備的狀況，輸入正確的磁碟機數。

(4)準備 2 片空白磁片（背面須開洞以便寫入）。

(5)按下 `I` 鍵，螢幕會問你在拷貝遊戲磁片以前，要不要先 Format，若你準備的空白片已 Format 好了，則按 `N`，否則按 `Y` 先規劃磁片再複製。

〔遊戲截圖〕

```
COPY SIDE 1.

WARNING!!! Formatting will destroy
the entire contents of the
destination disk. Do you want to
format the destination disk (Y/N)?

Insert Wasteland Master disk side 1
in drive 1.

                (RETURN)

1 2 3 4 Exit        Enter side # to copy.
```

(6)這時螢幕上的訊息，Master disk 代表遊戲母片，Destination Disk 表示待複製的空白片，依照螢幕上的指示，抽換磁片進行複製。直到顯示 “Copy Was Succesful” 字幕顯示後，表示該磁片已複製完成。

> 註：原文拼作 `Succesful`，英文原版為 `Successful`，照原樣轉錄。

(7)重複(5)、(6)的步驟，繼續複製 2.3.4. 面資料片，複製好的遊戲磁片請按 1.2.3.4. 標明順序。

(8)將母片妥為收藏，除 Boot 片用以開機外，以後皆以複製的遊戲磁片來進行遊戲。

#### (B) 載入遊戲

(1)若你剛才完成複製磁片的工作，尚未關機的話，這時按 Esc 鍵退回前頁選擇頁，再按 `S` 則載入遊戲。若是重開機，則將 Boot 面磁片置於 A 磁碟機中，待標題畫面出現後，按 `S` 即載入遊戲。

　　進入標題畫面中，有 Start 和 Utilies 兩項選擇，按 `S` 進入遊戲畫面，按 `U` 則進入公用程式，在公用程式下有下列數項選擇：

`R`estart — 若你的隊伍陷入無法動彈的困境，但又不願放棄這支隊伍時，可先用 Copy 指令另造四面新的資料片，然後按下此指令，依照螢幕上的指示分別插入舊的和新的資料片於磁碟機中，隊伍會重新回到 Ranger Cenger Center 附近，一切重新開始，人物依舊但身上的裝備和金錢將消失。

> 註：「Ranger Cenger Center」照原樣轉錄，原文即有此重複誤植。

`S`tart — 與標題畫面的 Start 功能相同。

### 三、人物的創設與檢閱

　　荒野遊俠是描述核戰後世界的冒險遊戲，為了調查沙漠中一連串的動亂，你率領麾下的沙漠流浪者（Rangers）四處探險，以查出隱藏在這些事件後的秘密。

　　只有在 Ranger Center 才能創造人物。遊戲開始時，電腦已為你造好了四名隊員分別是 Hell Razor、Angela Deth、Thrasher、和 Snake Vargns

> 註：第四名隊員原文作 `Snake Vargns`，英文原版為 `Snake Vargas`，照原樣轉錄。
