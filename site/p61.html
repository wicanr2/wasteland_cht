內容

（承 p.60）原子爐右方房間的密門打開後，隊伍一路往上， 從左上角的入口進入下水道。

下水道概況

作者形容 Vegas 的下水道「大得不太像話」，而且似乎是殺人機器的大本營。

難題一：渡過水道

第一個難題是如何渡過湍急的水道。解法：

幸好 L.I.V 身上還有根繩子，搭一道繩橋（站在水道岸邊，向下使用繩子即可）便過去了

〔機制斷言〕繩子作為道具使用、需要面向正確方向——見 mechanics-claims.md M-28。

難題二：敲起來空洞的牆

有些地方可以找到敲起來空洞的牆（圖上標有 Use Shovel 之處的碎牆）， 正好用當初在諾曼人營地挖寶的鏟子（Shovel）挖開。 處理完之後整個下水道就通行無阻了。

〔機制斷言〕特定牆面要用鏟子挖開才能通過——見 M-29。 〔對照〕原文此句作「如此整個徙水道便可通行無阻了」，「徙」應為「條」或「下」之誤植。 照原樣記，不改。

殺人機器與零件

四處和殺人機器對戰的結果，是得到一些能量武器、能源包， 以及四種用途不明的裝備：

零件原文英文
伺服馬達Sever motor
融合爐Fusion Cell
電路板Rom board
能源轉換器Power Conventer

〔對照〕Sever motor 應為 Servo motor，Power Conventer 應為 Power Converter。 兩處都是原文的拼寫，照原樣記，不改。

作者本來不相信 Max 是個機械人，但從散佈四處的零件和一個機械頭部看來， Charmaine 所言不虛。

原文註記：

註：地圖上標有攜帶該零件的機械人大概位置，各位只需直接收集這些零件，不必多打無用的仗。 此外，小心 Cyborg 和 Hexborg 這兩種敵人

〔機制斷言〕Cyborg 與 Hexborg 是下水道中特別危險的敵人——見 M-30。

組合室

最後抵達右下角的一個房間。房門沒辦法炸開，作者想到用音波鑰匙 （p.60 從蠍式身上取得）來試，果然應聲而開。

進去拿到最後一塊電路板之後，看到房間右側放著一排四個組合桌， 用來組合機械人。

〔機制斷言〕音波鑰匙開啟爆破無效的門——見 M-20。

Max 的組裝步驟（重要）

原文以註記的形式給出簡化過的操作序列。先說明編號方式：

走到組合桌上，由上而下是為 (1)、(2)、(3)、(4)

四張桌子的操作：

桌操作序列
(1)選 (2) → 原地使用 Android Head → 選 (2) → 原地使用電路板 → 移動至 (2)
(2)選 (2) → 原地使用融合爐 → 選 (2) → 原地使用能源轉換器 → 選 (2) → 原地使用伺服馬達 → 選 (2) → 原地使用電路板 → 選 (2) → 移動至 (3)
(3)選 (2) → 原地使用伺服馬達 → 選 (2) → 移動至 (4)
(4)選 (2) → 原地使用伺服馬達 → 選 (2) → 原地使用伺服馬達 → 選 (2)

完成後：

分別到 (1)(2)(3)(4)，各選 (3) 即可

零件用量小計（依上表）：

零件次數
Android Head1
電路板（Rom board）2
融合爐（Fusion Cell）1

〔機制斷言〕組裝流程中的「選 (2)」「選 (3)」是選單項次， (2) 疑為「使用／放置」、(3) 疑為「組裝／完成」。 原文沒有寫出選單的文字，只給編號——這一點要和逆向出來的選單對照，見 M-31。

結尾

四個部份組合起來後，Max 復活了。他告訴隊伍有關 Sleeper Base 和 Darwin Village 的事，並要隊伍從下方的門離開。

全文以一句留白收尾：

望著無垠的沙漠，我們坐下來休息一會兒。不知道我們的旅程還有多久才會結束？
