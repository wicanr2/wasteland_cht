# faithful-hd tileset 生成規則

每批固定 16 張、4×4，索引由左至右、由上至下。參考圖只提供格位、朝向、接邊與
功能語意；正式輸出不得逐像素放大原版。

- 每格後處理為 48×48 PNG。
- 嚴格正交俯視，不能改為等角透視。
- 地面、河流、道路與山脈過渡必須保留參考格四邊接點。
- 寫實、髒舊、低彩度的現代像素廢土；赭石、沙黃、鏽紅、灰藍。
- 禁止文字、編號、格線、品牌、既有 IP 角色與特定在世藝術家風格。
- 生成後先切片，再做尺寸、數量、alpha、接邊與實際地圖畫面驗收。
- 任一 gate 不過就標 rejected，不得寫進正式 bundle manifest。
